# NPC设定 V1：《地心之门》

> 本版将第一幕 NPC 分为三类：主要同伴 NPC、剧情/线索/阵营 NPC、纯粹 NPC。主要同伴保留完整游戏属性；剧情 NPC 保留人设和剧情功能，移除态度与战斗数值；纯粹 NPC 只保留地点功能。

---

## 一、主要同伴NPC

主要同伴 NPC 会固定加入主角团，或可被玩家招募进入无光孢海。此类角色保留：姓名、身份、参考人物原型、种族职业、性格、秘密、目标、初始态度、可触发事件、战斗能力。

### 1. 瑟琳·逆钟（固定核心同伴/时间魔法师）

| 项目 | 内容 |
|------|------|
| **姓名** | 瑟琳·逆钟 |
| **身份** | 第一幕初期受公会邀请加入主角团的时间魔法师，固定全程同行 |
| **参考人物原型** | 洛琪希《无职转生》 |
| **种族职业** | 魔族，外貌与人类基本无差异；法师/治疗者/时间魔法师 |
| **性格** | 文静、克制、强大、忧郁，对玩家有一种不合常理的尊重与崇拜 |
| **秘密** | 她来自地心狱门已经开启的未来。她知道玩家将在未来传说中成为唯一从“有去无回之地”返回的英雄，因此对玩家怀有压抑的崇拜与期待 |
| **目标** | 作为主角最重要的同伴陪同远征，引导玩家逐步接近真相，阻止失败未来发生 |
| **初始态度** | 85（表面保持距离，实际极度重视玩家安危） |
| **可触发事件** | ①在逆穹城召集队友阶段固定加入主角团 ②在缆梯途中说出“它比记录里更早开始发光了” ③玩家受伤时优先使用治疗魔法 ④玩家陷入时间幻觉时，她能提前提醒 ⑤第一幕不可揭露真实身份，只能留下异常 |
| **战斗能力** | AC14 HP34。法术位3级；掌握魔法飞弹、护盾术、治疗术、次级复原术、侦测魔法。平常时间魔法很弱，只能做到“把破碎的杯子还原”这类小规模回溯；只有主角团穿越地层、接近黑色方尖碑技术和时间锚点时，才能施展强大的时间魔法，引导队伍进入同一地层的过去、现在、未来 |

| **种族职业** | 男矮人，生存专家/厨师/近战斧战士 |

| **目标** | 带队穿越孢海，找回失踪采集队留下的铁锅徽记 |

|------|------|

| **身份** | 逆穹城雇佣剑士，前地表佣兵队副官 |
| **参考人物原型** | 卡思嘉《剑风传奇》 |
| **种族职业** | 女性人类，剑士/战斗大师 |

## 二、剧情/线索/阵营NPC

剧情 NPC 负责推动任务、展示阵营和提供关键线索。此类角色不加入主角团，不与主角一起战斗，也不依赖态度数值推进剧情。

### 7. 赫尔曼·断缆（逆穹城城防负责人）

| 项目 | 内容 |
|------|------|
| **姓名** | 赫尔曼·断缆 |
| **身份** | 逆穹城城防总长，降渊防线最高军事负责人 |
| **参考人物原型** | 埃尔文《进击的巨人》 |
| **种族职业** | 人类，指挥官 |
| **性格** | 冷静、强硬、极具战略眼光，能用平静语气下达残酷命令 |
| **秘密** | 他早已判断地底堡垒可能已经沦陷，但为了避免逆穹城恐慌，一直压下部分失联报告。他不是隐瞒真相取乐，而是认为城市不能在远征开始前崩溃 |
| **目标** | 守住逆穹城，确认地底堡垒真相，并在必要时切断所有通往地表的深层路线 |
| **第一幕功能** | 展示逆穹城的军事压力，说明地底堡垒失联的严重性，批准远征或提供城防视角情报 |

## 三、纯粹NPC

纯粹 NPC 不需要人物原型、不发展信任值、不提供复杂个人线。AI主持人使用他们时应以功能性台词为主。

| 人物 | 身份 | 功能 |
|------|------|------|
| 萨洛·杯底 | 回声酒馆老板 | 提供酒馆氛围、普通传闻、休整场景 |

| 奥布兰·晨爵 | 补给市场黑市商人 | 出售抗孢面罩、冷光灯、特殊补给，提示交易风险 |

## 四、同伴招募条件

| 同伴 | 条件 | 费用 |
|------|------|------|
| 瑟琳·逆钟 | 第一幕初期固定加入主角团 | 无费用，不占可招募同伴名额 |
| 森洛·铁锅 | 玩家尊重孢海生态，或在公会接受“寻找采集队徽记”支线 | 免费；要求玩家不要无故破坏真菌 |
| 莉亚瑟·青弦 | 在回声酒馆或公会大厅与她交谈，并承诺调查失踪精灵侦查队 | 赏金少量分成 |
| 卡西亚·断羽 | 玩家表现出保护平民或尊重牺牲者的态度 | 赏金对半分，或完成她的护送旧案线索 |
| 克莱娅·软爪 | 玩家需要侦查、潜行或解除机关时，可在补给市场附近招募 | 赏金少量分成；要求遵守分赃承诺 |
| 雷铎·炉心 | 玩家在旧矿道或公会仓库发现并修复他的盾臂后解锁 | 免费；需要定期维护核心 |

瑟琳·逆钟是固定同行的核心主线同伴，不占用可招募同伴名额。除瑟琳外，玩家最多同时带 2 名可招募同伴进入无光孢海。超出 2 名的同伴留在逆穹城或孢海据点待命。

## 五、AI主持人注意事项

1. 第一幕台词重心应放在瑟琳、玩家选择的可招募同伴、米蕾娜、赫尔曼和莱因。
2. 瑟琳是第一幕固定全程同行的核心同伴，必须参与接任务、准备、垂降、孢海探索和黑暗之门结尾，但不能在第一幕揭露来自未来。
3. 瑟琳平常的时间魔法很弱，只能做小规模回溯；强大时间魔法只在穿越地层、接近黑色方尖碑技术和时间锚点时出现。
4. 剧情 NPC 不发展复杂好感度，只在关键节点提供任务、线索和阵营压力。
5. 纯粹 NPC 只提供功能性对话，不要展开长篇个人剧情。
6. 赛因·镜页第一幕只是小角色，不能主动推动主线，也不能像主要反派一样干涉玩家。
7. 可招募同伴最多额外携带 2 名，避免队伍过大导致台词和行动分配失控。
