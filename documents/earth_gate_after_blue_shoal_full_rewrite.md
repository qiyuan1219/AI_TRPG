# 《地心之门》蓝伞浅滩后续剧情重写稿

> 用途：交给 Codex 直接实现后半段主线。  
> 范围：从蓝伞浅滩战斗胜利后开始，到最终四结局。  
> 目标阅读时长：单次正常通关约 15 分钟。  
> 文本标准：不是节点摘要，而是可直接放入游戏的 VN/AI 跑团剧情文本。  
> 实现原则：复用现有剧情、战斗、骰子、背包、线索、AI 续写、存档系统；不要走旧的蓝伞浅滩战后简化线。

## 0. 后半段整体剧情定位

蓝伞浅滩之前，玩家完成的是“组队、下潜、初见孢海、证明队伍能活下来”。  
蓝伞浅滩之后，剧情主题必须转为：

1. **远征队并不是单纯遇难，而是发现了堡垒真相。**  
2. **黑石门卫不是传统意义上的 Boss，它是被污染、被误解、仍在执行封印职责的守门者。**  
3. **莱因是四结局成立的关键证人。**  
4. **玩家最后不是选择“杀不杀 Boss”，而是选择如何处理一个仍在守门的受污染存在。**

后半段要给玩家一种感觉：

> 他们越靠近地心之门，越发现“敌人”并不清晰。真正危险的不是某只怪物，而是恐惧、误判、污染和时间。

## 2.1 入场剧情文本

战斗结束后，蓝伞浅滩没有立刻恢复安静。

那些被斩开的菌团仍在泥水里缓慢收缩，像一颗颗不肯承认死亡的心脏。蓝色孢尘从伞盖上落下来，在你们的肩头、发梢、盾牌边缘铺成一层微光。远处的水洼倒映着倒悬城市的轮廓，可那轮廓被涟漪切碎，看起来像一座正在沉没的城。

孢兽倒下的位置留下了一道拖拽痕。泥里没有正常野兽挣扎时会留下的爪痕，只有一排排细小、密集、像根须一样的沟槽。它并不是从浅滩深处冲出来的——它像是被什么东西从更远处牵引过来。

尼布站在哨棚边，手里的短矛还没有放下。他盯着那些根须沟槽，脸色比战斗时还差。

「它们不该来这儿。」尼布低声说，「蓝伞浅滩是浅层，孢兽会绕开这里。除非……除非下面有什么东西在叫它们。」

布洛克蹲在孢兽尸体旁，用斧背拨开一片湿烂的菌膜。他的眉毛皱得很深。

「不是正常孢化。」他说，「这玩意儿身上的菌丝像被拧成了缆绳。有人，或者有什么东西，把它们往一个方向拽。」

瑟琳没有马上接话。她抬起法杖，杖头的银色符文像钟摆一样轻轻震动。你听见极低的嗡鸣从地底传来，像一口埋在黑暗里的钟，被谁从很远的地方敲了一下。

艾琳合上双眼，圣徽贴在掌心。片刻后，她睁开眼，声音很轻。

「这里有很多恐惧。不是怪物的，是人的。」

凯娅靠在残破的木桩上，指尖转着匕首，目光扫过浅滩边缘那些凌乱脚印。

「有人从这里逃过去了。」她说，「而且不是很久以前。脚印被孢尘盖了一半，另一半还湿着。」

你们的目光同时落向浅滩尽头。

那里有一条被蓝伞菌遮住的小路，通向更深的孢海。路边挂着一块断裂的远征队标牌，上面只剩半行字：

> 第三远征队临时标记。禁止回应远处人声。

尼布咽了口唾沫。

「如果你们真要继续走，记住这句话。」他说，「在下面，能叫出你名字的，不一定是人。」

## 2.2 玩家选择：战后调查

本节点建议允许玩家选择 **2 个调查行动**。每个行动都有文本、检定、奖励。若当前系统暂时只支持一次选择，则优先保留“调查脚印”和“救治伤员”的二选一。

### 选择 A：检查孢兽尸体与根须沟槽

```ts
check: ecology || observe
DC: 13
success: blue_shoal_spore_sample = true; truthScore += 1; combatPrepScore += 1
partial: truthScore += 1
fail: player gains 'spore_sickness_minor'; no item
rewardItem: '蓝伞孢粉'
```

#### 成功文本

你蹲下身，用刀背挑开孢兽胸腹间的菌膜。菌膜之下没有完整的内脏，只有一团团被黑色根丝缠住的孢囊。那些根丝并不属于它，颜色太深，质地太硬，像从黑石里长出来的血管。

布洛克用小玻璃瓶接下一点蓝色孢粉，立刻塞紧瓶塞。

「这东西还能用。」他说，「正常蓝伞孢粉有净化孢毒的效果，虽然弱，但比空手强。要是后面遇到被污染的人，或许能救一下。」

瑟琳看着黑色根丝，神情凝重。

「孢兽不是自己变异的。它被某种封印残留牵引了。」

你获得了道具：**蓝伞孢粉**。  
你记录了线索：**孢兽体内存在黑色根丝，污染源来自更深处。**

#### 失败文本

你刚挑开菌膜，一股甜腻的蓝色雾气就从孢囊里喷出。艾琳立刻拉住你的手腕，将圣徽按在你掌心。

「别吸进去。」她低声说。

你退后两步，喉咙里却已经泛起一阵铁锈味。孢兽尸体很快塌成一滩发亮的污泥，能带走的样本被污染了。

获得状态：**轻微孢毒**。后续一次体质/医药相关检定 -1。

#### 成功文本

你沿着湿脚印往蓝伞菌背后走去。脚印起初杂乱，像逃亡者曾经在浅滩边跌倒过几次。再往前，它们忽然变得整齐——不是因为那个人恢复了冷静，而是因为他开始沿着同一条路线机械地走。

凯娅蹲下来，指尖按住一枚几乎陷进泥里的金属片。

「鞋钉。」她说，「军用的，逆穹城防制式。」

木桩下压着一本被水泡烂的巡逻记录。大部分字迹已经糊开，只剩几段还能辨认：

> ……第三晚，听见队长从东侧喊我。队长明明已经失踪两天。  
> ……禁止回应熟人的声音。  
> ……莱因说门里有人敲钟。不是求救，是警告。  
> ……黑石门卫没有追杀我们，它在挡住更里面的东西。

艾琳读到最后一句时，指尖微微收紧。

瑟琳低声重复：「黑石门卫……在挡住更里面的东西？」

你获得线索：**第三巡逻队记录**。  
真相分数 +1。

#### 失败文本

你追踪到浅滩边缘时，远处忽然传来一个熟悉的声音。

那声音很像米娜，带着公会柜台后那种冷静又疲惫的语气。

「委托人，请立刻返回。任务取消。」

队伍一瞬间停住。

尼布脸色惨白地抓住你的肩膀。

「别答。」他说，「别回头，别答应，别问为什么。」

当你们强迫自己离开时，脚印已经被新落下的孢尘盖住。逃亡者的方向变得模糊。

云苓的护身符如果在背包中，此处追加文本：

> 伤员表现出明显创伤反应，但污染未完全侵入心智。反复提及“门卫”“别杀它”“它还在守门”。建议若再次发现本人，优先稳定精神，不要强行审讯。

你获得线索：**伤员净化报告**。

你们尽力了，但浅滩缺少干净水和药剂。一个伤员在昏迷中反复抓住艾琳的袖口，嘴里只念着同一句话：

「门卫……不是怪物……」

他最终没有醒来。

艾琳替他合上眼。尼布没有责怪你们，只是把哨棚门口的灯压低了一些。

「下去吧。」他说，「至少把他没说完的话带回来。」

## 3.1 入场剧情文本

蓝伞浅滩之后，地势开始下沉。

泥水没过靴底，随后没过脚踝。脚下的路不再像路，更像一条被无数菌丝临时编出来的软桥。每走一步，桥面都会轻轻起伏，仿佛整片湿地正在缓慢呼吸。

所谓骨柱，并不是真的骨头。

那是古代堡垒坍塌后露出的白色支撑柱，外层被孢菌啃蚀，变得像巨兽肋骨一样弯曲。柱子之间缠着断裂的符文缆线，缆线早已失去金属光泽，却还会在你们靠近时发出微弱震颤。

瑟琳把手掌贴上一根骨柱。银色符文沿着她的指尖爬开，很快又被柱内的黑色纹路吞没。

「这里曾经是地底堡垒的外围传讯阵。」她说，「如果传讯阵还活着一点点，它可能记录过第三远征队的最后信号。」

布洛克立刻摇头。

「也可能记录过别的东西。孢海里最麻烦的不是毒，是模仿。它们学人的脚步、人声、求救，甚至学你心里最想听见的话。」

凯娅笑了一声，但那笑声没什么轻松。

「那它要是学金币掉地的声音，麻烦叫我一声。我可能会死得很快。」

艾琳望向湿地深处。那里有一簇白色骨柱围成的环，中间漂着一团淡淡的青光。青光一明一暗，像有人提着灯，在雾里等你们。

很快，你们都听见了。

「……救我。」

那声音从骨柱环里传来，嘶哑、断续、像喉咙里塞满了沙。

「我是……第三远征队……莱因……」

尼布的警告在你脑中回响：

> 在下面，能叫出你名字的，不一定是人。

## 3.2 路线选择

本节点建议做成一次重要选择，影响后续战斗地形、样本质量和莱因初见状态。

### 选择 A：沿骨柱高处绕行，避免直接回应声音

```ts

partial: route = 'safe'; one companion minor damage
fail: trigger spore slip; party starts next battle with minor debuff
```

#### 成功文本

你示意队伍不要回应那道声音，而是沿骨柱露出的横梁绕行。白色支撑柱表面湿滑，脚下每一次落点都像踩在生物的脊背上。

凯娅走在最前面。她用匕首轻敲柱面，听声音判断里面是否空 hollow。走到一半时，她忽然停住，反手按住你的肩。

下一秒，脚下的泥水无声裂开。一条伪装成藤蔓的舌状菌索从水里探出，正好扫过你们刚才本该走过的位置。

凯娅挑眉。

「看见没？不回话是好习惯。不乱走也是。」

你们避开了湿地中央的第一层陷阱。后续战前选择中，敌方伏击效果降低。

### 选择 B：立刻朝求救声方向前进

你选择朝声音方向前进，但没有贸然回应。艾琳跟在你身侧，圣徽压在胸前。那道声音一遍遍重复“我是莱因”，每重复一次，声线就变得更像一个真正的人。

走到骨柱环前，你忽然发现不对。

声音来自正前方，可泥水中的气泡却从左侧冒出。真正的呼吸声在左侧，那道求救只是湿地模仿出来的壳。

你抬手示意队伍转向。

骨柱环里的青光骤然暗下。泥水中有什么东西失望地沉了下去。

艾琳轻声说：「你听见的不是声音，是它希望你相信的东西。」

你们发现了真正的逃亡方向。莱因初见信任 +1。

# 13. Codex 实现要求

## 13.1 必须替换旧线

蓝伞浅滩战斗胜利后，不允许再进入旧的简化节点。必须改为：

```ts
battle_blue_shoal_result === 'win'
  -> after-battle-blue-shoal-rewrite
```

如果旧代码中有 `after-battle-blue-shoal`、`blue-shoal-victory`、`postBlueShoal` 等旧节点，要做兼容重定向：

```ts
oldAfterBlueShoalIds -> after-battle-blue-shoal-rewrite
```

## 13.2 AI 续写失败 fallback

任何“选择行动 → 等待 KP 回复”的节点，都必须有 deterministic fallback，不允许卡住。

建议结构：

```ts
const FALLBACK_STORY_BY_CHOICE = {
  'blue-shoal-investigate-corpse': successTextOrPartialText,
  'bone-wetland-track-voice': successTextOrFailText,
  'guardian-call-true-name': successTextOrPartialText,
}
```

若 AI 请求超时、返回空、格式错误：

1. 使用本文件对应分支文本。
2. 正常设置 flag / item / next。
3. 显示“KP 记录已自动整理”之类的轻提示即可，不要让玩家停在等待状态。

## 13.3 分支实现优先级

若开发时间有限，按以下优先级实现：

### P0 必做

# 14. 最重要的叙事约束

1. 莱因不能消失。即使玩家失败，也必须留下识别牌和最低限度证词。
2. 黑石门卫不能被写成普通反派 Boss。它是被污染的守门者。
3. 黑根要体现“模仿声音、连接记忆、污染命令”的特征，而不是普通藤蔓怪。
4. 四结局都要有道德重量，不能简单好/坏。
5. 玩家选择要影响最终结局，不只是影响一两句台词。
6. 伙伴必须有态度：瑟琳偏真相与逆钟方案，艾琳偏救赎，布洛克偏现实安全，凯娅偏证据与后手。
7. 后半段主线的核心情绪是：迟来的理解、带代价的补救、在误判之后承担选择。
