# 《地心之门》快速再部署教程

> 适用场景：服务器已有旧版本，现在要上传新版本并覆盖部署。  
> 服务器 IP：`114.132.232.194`  
> 项目路径：`/opt/earthgate`  
> 后端服务名：`trpg-backend`  
> 前端：React + Vite  
> 后端：FastAPI  
> 部署方式：Nginx 托管前端，`/api/` 代理到 FastAPI 后端。

---

## 一、部署流程总览

```text
本地打包新版本
→ 上传到服务器
→ 备份旧版本
→ 保留旧版 .env / data
→ 覆盖 /opt/earthgate
→ 安装后端依赖
→ 构建前端
→ 重启 trpg-backend
→ 重载 Nginx
→ 浏览器验证
```

---

## 二、本地打包新版本

在 Windows PowerShell 进入项目根目录：

```powershell
cd "C:\Users\黄锦意\Desktop\demo02"
```

删除旧压缩包：

```powershell
Remove-Item .\earthgate-new.tar.gz -Force -ErrorAction SilentlyContinue
```

重新打包：

```powershell
tar.exe --exclude="./node_modules" --exclude="./frontend/node_modules" --exclude="./frontend/dist" --exclude="./backend/.venv" --exclude="./backend/.python-deps" --exclude="./backend/__pycache__" --exclude="./backend/.pytest_cache" --exclude="./.pytest_cache" --exclude="./.git" --exclude="./logs" --exclude="./个人工作目录TRPG-*" -czf earthgate-new.tar.gz .
```

检查是否误打包：

```powershell
tar.exe -tf earthgate-new.tar.gz | Select-String "^./node_modules/|^./frontend/node_modules/|^./frontend/dist/|^./.git/|^./backend/.venv/"
```

如果没有输出，说明压缩包基本正常。

> 注意：`.gitignore`、`.gitkeep` 是普通文件，可以存在。真正不能出现的是 `./node_modules/`、`./frontend/node_modules/`、`./frontend/dist/`、`./.git/`、`./backend/.venv/`。

```powershell

```

如果提示 `~/upload/` 不存在，先登录服务器创建：

```bash

```

## 四、登录服务器

```powershell

确认上传文件存在：

```

应该能看到：

```text

```

## 五、覆盖部署

在服务器执行以下命令：

```bash
cd /opt

sudo tar -czf /opt/earthgate_backup_$(date +%Y%m%d_%H%M%S).tar.gz earthgate

sudo systemctl stop trpg-backend 2>/dev/null || true

mkdir -p ~/earthgate_keep
cp /opt/earthgate/backend/.env ~/earthgate_keep/.env 2>/dev/null || true
sudo cp -r /opt/earthgate/data ~/earthgate_keep/data 2>/dev/null || true
sudo chown -R ubuntu:ubuntu ~/earthgate_keep

sudo rm -rf /opt/earthgate
sudo mkdir -p /opt/earthgate
sudo tar -xzf ~/upload/earthgate-new.tar.gz -C /opt/earthgate
sudo chown -R ubuntu:ubuntu /opt/earthgate

cp ~/earthgate_keep/.env /opt/earthgate/backend/.env
rm -rf /opt/earthgate/data
cp -r ~/earthgate_keep/data /opt/earthgate/data
```

说明：

```text
/opt/earthgate_backup_时间.tar.gz  是旧版本备份
backend/.env                      保留 API Key 等环境变量
data/                             保留数据库与存档
```

## 六、更新后端依赖

```bash
cd /opt/earthgate/backend

python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
```

如果后端依赖没变化，也可以执行一遍，保证环境完整。

## 七、重新构建前端

```bash
cd /opt/earthgate/frontend

npm install
npm run build
```

构建成功后确认：

```bash
ls -lah /opt/earthgate/frontend/dist
```

## 八、重启服务

```bash
sudo systemctl daemon-reload
sudo systemctl start trpg-backend

sudo nginx -t
sudo systemctl reload nginx
```

## 十、常见问题处理

### 1. 后端启动失败

查看日志：

```bash
journalctl -u trpg-backend -n 100 --no-pager
```

常见原因：

```text
.env 不存在
API Key 错误
requirements.txt 依赖没装好
main.py 入口路径不对
端口 8000 被占用
```

---

### 2. AI 不回复

检查后端健康接口：

```bash
curl http://127.0.0.1:8000/api/dnd/health
```

查看后端实时日志：

```bash
journalctl -u trpg-backend -f
```

重点检查：

```text
DEEPSEEK_API_KEY 是否正确
Nginx /api/ 是否代理到 127.0.0.1:8000/api/
后端是否 active running
```

---

### 3. 页面 403 / 500

查看 Nginx 错误日志：

```bash
sudo tail -f /var/log/nginx/error.log
```

检查 Nginx 配置：

```bash
sudo nginx -t
```

修复权限：

```bash
sudo chmod +rx /opt
sudo chmod -R +rx /opt/earthgate/frontend/dist
sudo systemctl reload nginx
```

---

### 4. 图片、立绘、BGM 不显示

检查素材是否存在：

```bash
ls -lah /opt/earthgate/frontend/public/assets
```

重新构建前端：

```bash
cd /opt/earthgate/frontend
npm run build
```

注意：素材上传完成后必须重新 `npm run build`，否则 `dist` 里可能没有新素材。

---

### 5. 压缩包太大或上传慢

本地重新检查压缩包是否误带大目录：

```powershell
tar.exe -tf earthgate-new.tar.gz | Select-String "^./node_modules/|^./frontend/node_modules/|^./frontend/dist/|^./.git/|^./backend/.venv/"
```

如果有输出，删除压缩包后重新打包。

## 十二、回滚旧版本

如果新版本出问题，可以回滚最近一次备份。

查看备份：

```bash
ls -lh /opt/earthgate_backup_*.tar.gz
```

选择一个备份文件，例如：

```text
/opt/earthgate_backup_20260620_153000.tar.gz
```

执行：

```bash
cd /opt

sudo systemctl stop trpg-backend 2>/dev/null || true

sudo rm -rf /opt/earthgate
sudo tar -xzf /opt/earthgate_backup_20260620_153000.tar.gz -C /opt
sudo chown -R ubuntu:ubuntu /opt/earthgate

cd /opt/earthgate/frontend
npm install
npm run build

sudo systemctl start trpg-backend
sudo nginx -t
sudo systemctl reload nginx
```

然后访问：

```text
http://114.132.232.194/
```
