## 一、总体评价

蓝伞浅滩战后的扩展剧情（`POST_BLUE_SHOAL_SCENES`）在**核心idea**上非常到位——菌群集体迁徙沟痕、拟声菌团死后播放遗言、远征队营地细节、门内伪造命令——这些设定都很精彩。但**文笔执行度参差不齐**：

- **最好的段落**（aftermath / boneAftermath / camp）达到了前线组队阶段的文本标准
- **大量场景极其短促**（bonePrebattle 2行、fortressInner 2行、laineDecision 4行、campNight 4行），像分镜草稿而非成品叙事
- **同伴对话多处出现"轮流朗读三点"模板**，缺乏自然交错
- **结局文本最弱**，四个结局质量严重不均衡：A和D较好，B和C像一句话大纲

整体来看，核心问题是**信息有了，但缺少画面、呼吸和情感重量**。

## 二、逐场景诊断与修改建议

### 场景1：aftermath（蓝伞浅滩战后战场调查）— 质量：★★★★☆

**现有行数**：11行 | **建议行数**：保持

**问题**：
第103行「你们这才注意到，浅滩战场上散落着三类异常痕迹」——这句是典型说明文写法，把"菌群迁徙沟痕/封印余波/黑缆残片"像列清单一样总结出来。前面各同伴已经分别发现了这三类痕迹，此处再做"三类"总结是多此一举，读者已经能自己拼出画面。

**建议修改**（替换第103行）：
> 「菌毯上的拖痕、封印的余波、被整齐切开的缆线——这三样东西不该同时出现在同一片战场上。」

### 场景2：route（湿地岔路四条路线选择）— 质量：★★★☆☆

**现有行数**：9行 | **建议行数**：保持

**问题1**：第130行艾琳的台词「所以，发光桩道更安全，旧排水渠更适合绕行……」是对前面四人各自描述的四条路线的复读总结。前四人已经各自说得很清楚，艾琳再总结一次显得啰嗦且工整得不像真人对话。

**问题2**：第131行凯娅的「说简单点：稳路保命，暗路抢位，菌路拿情报，缆路赌大线索」——这种"四字对仗"在黑市角色口中太文绉绉了。

**建议修改**：
- 删除第130行艾琳的总结台词，改为她看向四条路的沉默描写
- 第131行凯娅台词改为更粗糙的口语：
> 「说白了。想活命走桩道，想占便宜钻渠，想弄明白走菌脊，想赌一把走缆索。你们定。」

### 场景3：boneInvestigation（骨柱湿地调查）— 质量：★★★☆☆

**现有行数**：13行 | **建议行数**：保持

### 场景18：endingC（冷静的远征）— 质量：★☆☆☆☆ 🔴

**现有行数**：3行 | **建议行数**：6-8行

**最差结局。** 第492行「这是一条理性、冷静而有效的道路。只是没有莱因的人证……永远留在了黑根深处」——这读起来像游戏评测，而不是叙事文本。玩家不需要被告知"这是一条理性冷静有效的道路"，他们应该通过画面感受到代价。

**建议重写**：聚焦于"没有莱因"的空缺——不是直接说"没有证人"，而是描写那种沉默：
```

队伍里的每一个人都还在——没有人倒下，没有人需要搀扶。
布洛克第一个走向门缝，凯娅跟在后面。艾琳停了一步。她回头朝骨柱湿地的方向看了一眼——那里什么都没有，只有黑暗和半埋在菌毯里的断裂骨柱。
瑟琳收起银杖。她没有记录任何东西。
```

## 四、可直接参考的优秀写法（来自同文件）

**最好的战争后描写**（aftermath第95行）：
```
「战斗结束后，蓝伞浅滩并没有真正安静下来。被斩碎的菌丝散落在浅水与岩缝之间，仍一下一下抽动，像某种濒死的东西还在隔着地面呼吸。」
```

**最好的遗物发现**（camp第236行）：
```
「艾琳在医疗帐门口找到一行用炭写下的字：'仍能说出自己名字的人，先救。'旁边的计数每天都在减少，却从未归零。」
```

**最好的胁迫感**（afterBoss第416行）：
```
「最后，所有声音合成一个与你完全相同的声音：'你已经走到这里了。现在只差最后一步。'」
```

**写作原则总结**：
- 先给画面，再给台词
- 同伴不要轮流说结构相同的话
- 不要替玩家总结"这是什么性质的选择"
- 关键情感时刻用沉默和动作，不靠解释
