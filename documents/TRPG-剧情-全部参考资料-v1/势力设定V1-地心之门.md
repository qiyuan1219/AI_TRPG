# 势力设定 V1：《地心之门》

---

## 势力总览

本文件用于说明《地心之门》中各主要势力的宏观定位、目标、资源、对玩家态度和第一幕剧情功能。当前项目只制作第一幕，因此本版重点服务**逆穹悬城、降渊缆梯、无光孢海、黑暗之门**相关内容；第二幕之后的势力只保留必要伏笔，不展开完整剧情线。

| 势力 | 性质 | 核心目标 | 对玩家态度 | 第一幕作用 |
|------|------|----------|------------|------------|
| **逆穹悬城城防体系** | 地下城邦防卫力量 | 守住逆穹悬城，阻止深层魔物上涌 | 谨慎合作 | 提供危机压力、通行许可、军事视角 |
| **逆穹悬城冒险者公会** | 任务与远征管理组织 | 调查地底堡垒失联，组织深层远征 | 雇主 / 合作者 | 发布主线委托，介绍路线和同伴 |
| **匠炉区与降渊工程师** | 工程与补给体系 | 维护逆穹悬城、降渊缆梯和远征装备 | 功能性友好 | 支撑垂降 CG、装备维修和工程线索 |
| **地表边境委托方** | 背景雇主 / 受害者 | 阻止地下魔物袭击地表 | 期待玩家成功 | 提供玩家下地的初始动机 |
| **地底堡垒守军残余** | 失联防线 / 旧盟友 | 镇守地心狱门路线，完成未竟职责 | 破碎盟友 | 通过遗物和幸存者提供恐怖线索 |
| **无光孢海生态** | 中立危险生态 / Araumycos 远端菌脉 | 隔离污染，维持自身生态 | 非善非恶 | 第一幕主要环境势力和探索压力 |
| **孢化魔物与深层污染生物** | 怪物阵营 | 被本能、孢子和炼狱污染驱动 | 敌对 | 教学战斗与正式战斗的主要敌人来源 |
| **黑石观测与研究系统** | 奥术研究 / 情报辅助 | 理解黑石脉冲和深层异常 | 谨慎中立 | 提供黑色方尖碑技术伏笔 |
| **地心狱门污染** | 隐藏终局威胁 | 扩大封印裂隙，连接阿弗纳斯 | 隐藏敌对 | 第一幕只以污染、符纹和热流形式出现 |
| **未来时间线干涉者** | 开发者隐藏势力 | 改写地心狱门开启的失败未来 | 隐藏友方 | 第一幕主要通过瑟琳埋伏笔 |

## 势力一：逆穹悬城城防体系

### 总述

逆穹悬城城防体系负责维持倒挂城市的安全、缆梯区域秩序、深层警戒和地表通道管制。它不是传统王国军队，而是由城防军、缆道守卫、巡逻队、符文炮台维护者和外环守卫共同构成的地下城邦防卫力量。

近年地下魔物上涌频率增加，城防体系已经处于长期高压状态。城防负责人清楚地知道：如果地底堡垒已经失守，逆穹悬城就是阻止深层灾害继续上涌的最后文明屏障。

### 核心目标

1. 守住逆穹悬城和地表通道。
2. 防止魔物从孢海、裂隙或旧矿道进入城市。
3. 控制地底堡垒失联消息，避免城市恐慌。
4. 在必要时切断部分深层路线。

### 代表人物

| 人物 | 身份 | 剧情功能 |
|------|------|----------|
| **赫尔曼·断缆** | 逆穹悬城城防负责人 | 提供军事压力、批准远征、暗示堡垒失联严重性 |
| 黑缆守卫队 | 缆梯与城防守卫 | 维持秩序，展示逆穹悬城戒备状态 |
| 城门守卫 / 巡逻队 | 城市基础防卫人员 | 教学战斗、入城检查、危机氛围 |

### 对玩家态度

城防体系不会轻易相信地表来的新冒险者，但会接受玩家作为远征队执行高风险任务。玩家表现出冷静、守纪律和保护平民的倾向时，城防会更愿意提供情报。

### 第一幕功能

- 通过教学战斗展示魔物已经开始靠近城市。
- 通过赫尔曼说明地底堡垒失联的严重性。
- 签发玩家前往降渊缆梯和孢海据点的通行许可。
- 为逆穹悬城增加“奇迹工程也正在承压”的现实感。

## 势力二：逆穹悬城冒险者公会

### 总述

逆穹悬城冒险者公会是第一幕的主线任务发布者。它不是普通酒馆任务板，而是完整的远征管理机构，负责登记冒险者、组建队伍、备案路线、发放补给建议、保存失踪档案和处理抚恤记录。

公会知道地底堡垒失联十年，也知道过去多支队伍没有回来。它仍然发布任务，不是因为冷血，而是因为如果无人继续向下，地表和逆穹悬城迟早会被深层灾害吞没。

### 核心目标

1. 组织新一轮深层远征。
2. 查明地底堡垒失联真相。
3. 确认地心狱门相关传说是否正在变成现实威胁。
4. 尽可能让远征者活着回来，并记录真实路线。

### 核心资源

| 资源 | 用途 |
|------|------|
| 远征档案 | 提供失踪队伍、旧路线、黑暗之门记录 |
| 任务委托 | 推动玩家公开目标 |
| 队伍登记 | 解释同伴选择机制 |
| 补给建议 | 引导购买抗孢面罩、冷光灯、绳索等 |
| 公会信誉 | 让玩家行动具有合法性 |

### 代表人物

| 人物 | 身份 | 剧情功能 |
|------|------|----------|
| **米蕾娜·白契** | 冒险者公会任务官 | 发布任务、解释路线、保存远征记录 |
| 烛账帕维 | 公会档案员 | 查询失踪队伍资料，补充文书功能 |
| 可选同伴登记成员 | 登记冒险者 | 在组队阶段供玩家选择 |

### 对玩家态度

公会将玩家视为高风险任务的执行者。态度整体合作，但不会承诺安全。它会给出公开信息，也可能保留部分容易引发恐慌的记录。

### 第一幕功能

- 明确玩家初始目标：前往地底堡垒、调查失联、找到地心狱门、阻止魔物上涌。
- 交代“地底堡垒理应位于无光孢海下一层”的旧路线认知。
- 展示五名可选同伴的职业和功能。
- 将玩家从城市探索自然导向降渊缆梯和无光孢海。

## 势力三：匠炉区与降渊工程师

### 总述

匠炉区和降渊工程师是逆穹悬城能够存在的技术基础。没有他们，倒挂城市无法维持重力反转，降渊缆梯无法安全运转，远征者也无法获得适合幽暗地域的装备。

这个势力本身不负责主线决策，但它掌握着大量工程侧线索：锚柱震颤、缆梯记录错位、黑石脉冲干扰、吊舱旧血迹和设备异常。

### 核心目标

1. 维护逆穹悬城的锚柱、符文和缆索。
2. 保障降渊缆梯正常运行。
3. 为远征队提供装备维修和工程建议。
4. 查明黑石脉冲对城市工程的影响。

### 代表人物

| 人物 | 身份 | 剧情功能 |
|------|------|----------|
| **温妮娅·铜铃** | 降渊缆梯总工程师 | 说明缆梯结构，启动垂降，提供工程线索 |
| 铁砧玛尔加 | 匠炉区武器店主 | 出售和修理装备 |
| 缆梯维护工 | 工程人员 | 氛围与功能 NPC |

### 对玩家态度

整体功能性友好。只要玩家尊重工程规则、不乱碰设备、愿意听安全说明，工程师会提供帮助。鲁莽玩家会遭到严厉训斥，但通常不会阻断主线。

### 第一幕功能

- 让降渊缆梯成为可信的奇迹工程，而不是单纯交通工具。
- 将黑石异常转化为可感知的工程问题。
- 通过缆梯垂降完成第一幕从文明区到危险区的视觉转场。

## 势力四：地表边境委托方

### 总述

地表边境委托方包括受地下魔物袭击的村镇、矿业行会、商路护卫、地方领主和地表冒险者网络。它们不是第一幕主要出场势力，但提供玩家下地的初始动机。

玩家来自地表，之所以抵达逆穹悬城，是因为魔物已经不再局限于地下。地表的危机让“调查地底堡垒”不只是地下城邦内部事务，而是整个上下世界共同面对的问题。

### 核心目标

1. 阻止魔物继续袭击地表。
2. 查明地下裂隙和旧矿道为何突然失控。
3. 恢复商路、矿道和边境村镇安全。
4. 依赖逆穹悬城和冒险者公会解决深层源头。

### 对玩家态度

期待、依赖、信息有限。地表委托方知道“魔物从地下来”，但不了解幽暗地域深层真相。它们适合作为开局背景，不适合在第一幕占用过多戏份。

### 第一幕功能

- 解释玩家为什么从地表来到逆穹悬城。
- 强化任务紧迫感：如果深层问题不解决，地表会继续受害。
- 为后续结局提供回响：玩家是否真正阻止灾害，会影响地表命运。

## 势力五：地底堡垒守军残余

### 总述

地底堡垒守军曾是镇守深层路线和地心狱门传说的军事力量。十年前堡垒失联后，这一势力在第一幕中不以完整组织形式出现，而是以遗物、徽记、残破记录、旧路线牌和幸存者精神崩溃的方式存在。

对玩家而言，地底堡垒守军残余是“失踪的盟友”。他们不是敌人，而是已经被深层异常压垮的前线防线。

### 核心目标

1. 镇守通往地心狱门的深层路线。
2. 阻止污染和魔物继续向上涌出。
3. 将堡垒失联真相传回逆穹悬城。
4. 即使防线崩溃，也留下足够线索指引后来者。

### 代表人物与遗留物

| 内容 | 类型 | 剧情功能 |
|------|------|----------|
| **莱因·铁脊** | 幸存者 | 第一幕恐怖线索核心，提示门后异常和堡垒失联并非普通袭击 |
| 地底堡垒徽记 | 遗物 | 证明守军痕迹已经出现在孢海据点和深处 |
| 旧路线牌 | 路线物证 | 建立“黑暗之门后应是堡垒层”的玩家预期 |
| 破损营牌 | 远征残留 | 连接公会远征队和堡垒失联事件 |

### 对玩家态度

守军残余本身不再具备完整组织意识。幸存者可能恐惧、混乱、警惕，但本质上希望后来者完成他们未能完成的任务。

### 第一幕功能

- 将“地底堡垒失联”从公会档案变成玩家亲眼见到的恐怖现实。
- 提供黑暗之门附近异常的第一手证词。
- 暗示堡垒守军经历的不是普通魔物袭击。

## 势力六：无光孢海生态

### 总述

无光孢海不是传统意义上的组织，但在第一幕中应被视为一个“生态势力”。它是 Araumycos 的异常远端菌脉，拥有自我调节、记忆、扩张、隔离污染和回应刺激的能力。

它不是善良盟友，也不是纯粹敌人。它会吞噬尸体、诱捕猎物、制造幻觉，也可能是在本能地包裹黑暗之门附近的污染源，阻止更深层的东西继续外溢。

### 核心目标

1. 维持自身生态循环。
2. 分解死亡生物，吸收记忆和营养。
3. 隔离黑暗之门附近的深层污染。
4. 对外来者进行本能反应：诱捕、驱逐、记录或同化。

### 表现方式

| 现象 | 势力表现 | 游戏用途 |
|------|----------|----------|
| 孢子记忆 | 记录远征者声音和死亡瞬间 | 恐怖线索 |
| 模声菌囊 | 模仿求救声 | 判断与陷阱 |
| 光诱捕 | 用荧光引诱猎物 | 探索危险 |
| 菌丝包裹黑石 | 试图隔离异常源 | 主线伏笔 |
| 蕈人迁徙痕迹 | 暗示曾有中立地下生态群落 | 后续可扩展 |

### 对玩家态度

中立危险。玩家尊重孢海生态、谨慎行动、避免无意义破坏时，AI 主持可以降低遭遇压力或提供安全路线；玩家鲁莽制造噪音、乱碰荧光真菌、随意焚烧菌毯时，孢海会通过孢子幻觉、寄生体和路线迷失进行反击。

### 第一幕功能

- 成为第一幕的主要探索环境。
- 提供视觉奇观与真菌恐怖。
- 将 DND 幽暗地域真菌生态转化为可游玩的检定、状态和遭遇。
- 让玩家感到地下世界远比普通地牢庞大、古老和危险。

## 势力七：孢化魔物与深层污染生物

### 总述

孢化魔物与深层污染生物是第一幕主要敌对遭遇来源。它们不是完整地狱军团，也不是有严密组织的反派军队，而是被无光孢海孢子、地下生态压力、黑石异常和炼狱热流共同影响的怪物群。

这类敌人应表现为“危机正在外溢”的症状，而不是最终源头。

### 典型类型

| 类型 | 出现场景 | 功能 |
|------|----------|------|
| 裂隙爬兽幼体 | 逆穹悬城教学战斗 | 低难度、玩家必胜、熟悉规则 |
| 孢化地底兽 | 无光孢海正式战斗 | 正面威胁，展示污染生态 |
| 孢丝寄生体 | 无光孢海正式战斗 | 拖拽、侧翼、保护队形压力 |
| 炼狱热斑 | 战场环境危险 | 暗示阿弗纳斯污染外溢 |
| 被菌丝驱动的尸体 | 恐怖遭遇 | 展示孢海生态残酷性 |

### 核心目标

这类生物没有清晰政治目标，主要由本能驱动：

1. 捕食。
2. 扩散孢子。
3. 保护污染巢区。
4. 被深层热流和黑石异常吸引。
5. 向上层路线游荡，造成地表和城市危机。

### 对玩家态度

敌对。它们适合承担教学战斗、正式战斗、环境危险和追逐压力，但不应在第一幕承担复杂反派戏份。

## 势力八：黑石观测与研究系统

### 总述

黑石观测与研究系统包括逆穹悬城黑石观测台、少数奥术研究员、公会档案员和工程记录人员。他们负责记录地脉、黑石脉冲、深层异常和远征队报告。

这个势力不是第一幕反派，也不是秘密邪教。它的作用是让玩家通过“研究记录”和“异常读数”理解：深层问题不只是魔物变多，而是地理、生态、封印和时间都在出现不稳定迹象。

### 核心目标

1. 记录黑石脉冲和地脉异常。
2. 解释降渊缆梯、锚柱和旧地图中的矛盾。
3. 为公会和城防提供风险评估。
4. 尽量避免未经证实的信息引发城市恐慌。

### 代表人物

| 人物 | 身份 | 使用规则 |
|------|------|----------|
| 赛因·镜页 | 黑石观测台普通研究员 | 第一幕只是可疑小角色，不参与或干涉主线 |
| 公会档案员 | 记录人员 | 提供远征记录和日期矛盾 |
| 工程记录员 | 技术人员 | 提供缆梯维护记录和设备异常 |

### 对玩家态度

谨慎中立。玩家通过奥秘、调查、历史等方式追问时，可以得到部分线索；但研究系统不会主动把完整真相交给玩家，因为他们自己也没有完全理解黑色方尖碑技术。

### 第一幕功能

- 提供黑色方尖碑技术的早期线索。
- 避免所有情报都由 NPC 口头说明，让玩家可以通过资料、读数和检定主动发现异常。
- 保持赛因·镜页的低权重：他可以可疑，但不能成为第一幕主线操盘者。

## 势力九：地心狱门污染

### 总述

地心狱门污染是本作隐藏终局威胁在第一幕的外溢表现。它不是完整登场的组织，而是一种从深层封印裂隙渗出的位面污染。其真正源头是通向九层地狱第一层阿弗纳斯的地心狱门。

第一幕中，这股力量只能以残片、气息、热流和污染症状出现，不能过早变成完整地狱军团或解释全部真相。

### 核心目标

从开发者角度看，地心狱门污染的趋势是：

1. 扩大封印裂隙。
2. 腐蚀地下生态和魔物。
3. 影响黑暗之门附近的封印结构。
4. 让地狱力量逐步接近物质世界。
5. 为后续地狱之龙和阿弗纳斯军团登场埋伏笔。

### 第一幕表现

| 表现 | 玩家可知程度 |
|------|--------------|
| 炼狱热斑 | 玩家知道这不是普通地热 |
| 烧焦金属残片 | 玩家知道它与地底堡垒和深层污染有关 |
| 阿弗纳斯符纹残片 | 检定成功可感到炼狱气息，但不完整解释 |
| 孢化魔物身上的灼热纹路 | 玩家知道污染不只来自孢子 |
| 黑暗之门前庭异常 | 玩家知道门体受更深层力量影响 |

### 对玩家态度

隐藏敌对。第一幕不要让它以“会说话的反派组织”形式出现。它应像远处即将醒来的灾难，让玩家通过现象逐渐意识到真正敌人仍在更深处。

## 势力十：未来时间线干涉者

### 总述

未来时间线干涉者是开发者隐藏势力，目前第一幕只通过**“银杖”瑟琳**一人表现。它不应在第一幕作为公开组织登场，也不应被 NPC 直接命名。

这个势力来自地心狱门已经开启的失败未来。在那个未来，阿弗纳斯的地狱军团已经进入物质世界，封印体系几乎彻底崩溃。瑟琳回到当前时间线，是为了找到未来传说中唯一从“有去无回之地”返回的英雄，也就是玩家。

### 核心目标

1. 阻止地心狱门开启的失败未来发生。
2. 引导玩家接近三件封印圣遗物和黑色方尖碑时间核心。
3. 在不破坏时间闭环的前提下，让玩家逐步发现真相。
4. 保护玩家，但不能替玩家完成关键选择。

### 第一幕表现规则

- 瑟琳最早认识玩家，最早入队，固定全程同行。
- 她可以表现出提前知道某些危险。
- 她可以对黑石、封印纹路和莱因症状表现出异常熟悉。
- 她平常时间魔法很弱，只能做小规模回溯。
- 第一幕绝不能揭露她来自未来。

### 对玩家态度

隐藏友方。瑟琳实际极度重视玩家安危，但表面保持克制。她的目标不是控制玩家，而是让玩家活着走到真正需要做选择的地方。

## 第一幕势力使用规则

1. 第一幕台词和行动重心应放在：冒险者公会、城防体系、工程师、无光孢海生态、地底堡垒残余和污染魔物。
2. 玩家在逆穹悬城接触的是“文明秩序之间的紧张合作”，不是传统王国宫廷斗争。
3. 无光孢海不是敌方组织，而是中立危险生态。它可以伤害玩家，也可能正在隔离更深层污染。
4. 地心狱门污染是隐藏敌对势力，第一幕只能通过现象出现，不要让魔鬼军团或地狱之龙提前登场。
5. 未来时间线干涉者第一幕只能通过瑟琳的异常表现埋伏笔，不能公开解释。
6. 堕落法师和深层邪教不应在第一幕主动干涉主线，避免让第一幕势力过载。
7. 赛因·镜页第一幕只是小角色，不能成为幕后黑手或推动主线的关键反派。
8. 各势力应服务玩家行动选择：接任务、买补给、查档案、取得通行、选择同伴、穿越孢海、理解线索。
9. NPC 不应代表势力抢走玩家主角位置。势力提供压力和选择，玩家负责决定路线。
10. 黑暗之门前不要通过势力台词提前明示地下海洋反转；只建立“旧路线认为门后应是堡垒层”的预期。
