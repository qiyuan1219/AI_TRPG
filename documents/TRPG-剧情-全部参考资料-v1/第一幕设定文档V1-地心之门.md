# 第一幕设定文档 V1：《地心之门》

---

## 一、第一幕定位

当前项目只制作第一幕，因此第一幕需要承担完整 demo 的展示功能：让玩家完成接任务、准备、垂降、探索、遭遇危险、发现主线线索，并在结尾进入下一幕钩子。

**核心体验**：高魔 DND 地下冒险、幽暗地域奇观、真菌恐怖、垂直空间震撼。

**世界观底盘**：被遗忘国度的幽暗地域。  
**核心改动**：时间水晶改为黑色方尖碑技术的地心变体。  
**终局门户**：“地狱之门”改名为“地心狱门”，实际通向九层地狱第一层阿弗纳斯。

玩家是来自地表的冒险者，可以自由选择职业。由于地下魔物频繁袭击地表，玩家接受地下冒险者公会委托，前往地底堡垒调查失联真相，并确认地心狱门封印是否正在崩坏。

---

## 二、灵感来源

本幕主要参考 DND 官方世界观中幽暗地域的地下文明、危险生态和深层探索气质。无光孢海参考《Out of the Abyss》中 Neverlight Grove、蕈人、孢子污染和幽暗地域真菌生态的氛围，并结合 Araumycos 这一巨大地底真菌生命体的概念，改造成适合本项目第一幕的原创地点。

黑色方尖碑、时间异常和地心深处的封印结构参考 DND 中多次出现的黑色方尖碑线索，但本项目将其改写为“黑色方尖碑技术的地心变体”。地心狱门的终局威胁参考九层地狱第一层阿弗纳斯的炼狱战争、魔鬼军团和地狱巨龙意象。

以上来源只作为世界观底盘和风格灵感，不直接照搬官方剧情。

---

## 三、第一幕故事概要

玩家抵达幽暗地域中的最后大型文明据点：**颠倒城市“逆穹悬城”**。

这座城市倒挂在巨大地下洞穴的穹顶之上，是地表王国、矮人工匠、地底侏儒工程师、卓尔流亡者和魔法学院共同建造的奇迹。十年前，更深处负责镇守地心狱门的地底堡垒突然失联。近年，魔物开始沿地下裂隙和旧矿道向地表涌出。

玩家在逆穹悬城接取委托、准备补给，并遇到一位掌握时间魔法的神秘法师。随后，玩家乘坐城市核心的巨大缆梯，垂降到洞穴底部的前线据点，进入一片被称为**无光孢海**的巨大真菌生态区。

在孢海深处，玩家发现一座被黑色方尖碑碎片和菌丝包裹的古代入口：**黑暗之门**。门后传来的不是岩洞风声，而是海浪声。第一幕结束，第二幕“地下海洋”开启。

## 四、核心地点一：颠倒城市“逆穹悬城”

### 4.1 城市概念

逆穹悬城不是新手村，而是一座完整地下城邦。城市倒挂在巨大洞穴的穹顶上，由重力反转符文、秘银主缆、矮人锚柱和奥术加固法阵固定。

玩家第一次进入时，应感受到强烈视觉冲击：街道、尖塔、神殿和工坊全部悬在头顶岩穹之下；城市中央有一座巨大的垂直深井，通往洞穴底部；远处黑暗中，能隐约看到无光孢海的蓝绿色荧光。

### 4.2 城市功能

| 区域 | 功能 |
|------|------|
| 冒险者公会大厅 | 接任务、登记职业、查看失踪远征队记录 |
| 补给市场 | 购买武器、防具、药剂、抗孢面罩、冷光灯 |
| 匠炉区 | 修理装备，了解城市工程和深层矿道 |
| 静默神殿 | 治疗、祈祷、查询远征者遗体记录 |
| 黑石观测台 | 观测地脉震动和时间异常 |
| 回声酒馆 | 打听情报，触发同伴与传闻 |
| 降渊缆梯中枢 | 通往无光孢海据点的核心交通设施 |

### 4.3 居民生态

逆穹悬城居民种族复杂，包括人类、矮人、精灵、卓尔、地底侏儒、灰矮人、龙裔、提夫林等。这里的混居不是和平理想，而是生存需要。能长期生活在逆穹悬城的人大多强悍、务实、警惕，对地表冒险者既欢迎又不完全信任。

城市居民普遍知道三件事：

1. 地底堡垒已经失联十年。
2. 过去多支远征队进入深层后没有回来。
3. 最近魔物活动变得异常频繁，情况比公会公开说法更严重。

## 五、核心地点二：降渊缆梯

降渊缆梯是逆穹悬城的核心工程，也是第一幕重要 CG 节点。它由九条秘银主缆、三十六条黑铁副缆、符文制动轮和重力稳定环构成，从倒挂城市中央垂向洞穴底部。

**CG画面重点**：

1. 玩家站上吊舱，头顶是倒挂城市的灯火。
2. 吊舱脱离平台，城市逐渐远去。
3. 深渊中的风声压过人声，远处有飞行魔物掠过。
4. 下方无光孢海逐渐亮起，像一整片会呼吸的蓝绿色星云。
5. 时间魔法师望向孢海深处，说出一句不自然的话，例如：“它比记录里更早开始发光了。”

**可用检定**：

| 场景 | 检定 |
|------|------|
| 适应重力变化 | 体质 DC10 |
| 发现吊舱旧血迹 | 调查 DC10 |
| 抵抗孢子雾幻觉 | 体质 DC13 |
| 观察下方异常路线 | 感知 DC12 |

检定失败不阻断流程，只造成轻微代价，例如短暂幻觉、装备滑落、吸入孢尘或看到未来残影。

## 六、核心地点三：无光孢海

### 6.1 来源

无光孢海是 Araumycos 的一条异常远端菌脉。它可以参考《Out of the Abyss》中幽暗地域真菌生态、蕈人、Neverlight Grove、孢子污染和恶魔侵蚀的气质，但不直接照搬官方剧情。

“无光”不是指这里完全黑暗，而是指这里没有太阳、月亮、火把或神圣光辉意义上的正常光。孢海中的荧光来自真菌通讯、诱捕反应、孢子扩散和魔法污染。这里越美，往往越危险。

### 6.2 视觉概念

无光孢海不是森林，而是覆盖洞穴底部的巨大真菌海：

- 巨型蘑菇像塔楼一样升起。
- 骨白色菌柱构成天然迷宫。
- 地面孢毯会在脚下渗出蓝色光点。
- 空中漂浮荧光孢子云。
- 某些菌囊会模仿失踪者的求救声。
- 深处的菌丝低鸣像地下世界在说梦话。

### 6.3 生态规则

| 规则 | 游戏表现 |
|------|----------|
| 孢子记忆 | 玩家可能听见失踪远征队的声音 |
| 光诱捕 | 美丽荧光可能引诱玩家走入陷阱 |
| 菌丝传讯 | 大声行动会引来魔物 |
| 死体再生 | 死去生物被菌丝短暂驱动 |
| 时间错芽 | 真菌同时呈现幼体、成熟体和枯死体 |

### 6.4 可探索分区

| 区域 | 作用 |
|------|------|
| 孢海据点 | 缆梯终点，半废弃安全点，发现失踪队伍痕迹 |
| 蓝伞浅滩 | 新手探索区，低危真菌和基础检定 |
| 回声菌林 | 恐怖区，出现模仿人声的菌囊 |
| 骨柱湿地 | 危险移动区，菌毯陷落和寄生魔物 |
| 黑石根区 | 主线线索区，发现黑色方尖碑碎片和时间错芽 |
| 黑暗之门前庭 | 第一幕终点，通往第二幕 |

## 七、第一幕任务流程

1. **抵达逆穹悬城**  
   玩家进入倒挂城市，第一次看到幽暗地域文明奇观。

2. **前往冒险者公会**  
   公会说明地底堡垒失联、魔物上涌、深层路线中断等情况。

3. **准备阶段**  
   玩家购买补给、打听情报、查看失踪远征队记录，并与时间魔法师同行。

4. **乘坐降渊缆梯**  
   从城市垂降到洞穴底部，完成第一幕视觉转场。

5. **抵达孢海据点**  
   玩家发现据点半废弃，前队伍留下破损营牌和地底堡垒徽记。

6. **穿越无光孢海**  
   玩家遭遇孢子幻觉、真菌陷阱、寄生魔物和时间异常。

7. **发现黑石根区**  
   玩家找到黑色方尖碑碎片，确认此地异常不仅是自然生态问题。

8. **抵达黑暗之门**  
   玩家开启古代入口，门后传来海浪声，进入第二幕钩子。

## 九、黑暗之门

黑暗之门不是地心狱门本体，而是通向更深封印路线的第一道时空闸门。它位于无光孢海深处，由黑色方尖碑碎片、古代封印符文和结晶菌丝共同构成。

门体开启时，玩家会看到三个异常：

1. 门后吹来潮湿海风。
2. 门框符文出现过去、现在、未来三圈纹路。
3. 时间魔法师表现出不合常理的熟悉与沉默。

黑暗之门通向第二幕“地下海洋”。此处只作为第一幕结尾钩子，不展开第二幕内容。

## 十、AI主持人注意事项

1. 不要把逆穹悬城写成普通新手村，它必须是第一幕最大的文明奇观。
2. 不要把无光孢海写成普通地下森林，它是巨大、活体化、危险的真菌生态海。
3. 玩家每到一个地点，都应有可互动选择：调查、交涉、购买、观察、检定、移动。
4. 时间魔法师只能表现异常，不能在第一幕揭露来自未来。
5. 黑色方尖碑、时间异常、地心狱门都只埋伏笔，不要完整解释。
6. 第一幕结尾必须让玩家产生疑问：为什么门后不是堡垒，而是地下海洋？
