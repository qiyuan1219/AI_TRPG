## 二、关键验证结论

### 🟢 防御技能（#3）——全链路验证通过

```
玩家选择"防御" 
  → skillId="guard", targetType="self", requiresHitRoll=false
  → 后端执行: 写入 statuses: [{ type: "damage_reduction_once", value: 0.5 }]
  → 敌人锁定并攻击该角色:
    ├─ 命中 → _apply_damage → reduction_multiplier *= (1-0.5)=0.5 → 伤害减半 → 状态消耗
    └─ 未命中 → 不进入 _apply_damage → 防御状态保留
```

### 🟢 治疗药水（#12）——完整流程

```
点击治疗药水 
  → HealingTargetModal 选择目标 
  → rollHealing: 生成 D12 骰子事件 
  → DiceRollOverlay 播放动画（dieType="d12"）
  → 显示重投按钮（虚构骰子/万能骰子可用）
  → finishHealing: 结算恢复量 → 扣除药水 → 提示恢复量
```

### 🟢 瑟琳HP（#5）——运行时标准化机制

`getBattleConfigById` 函数（`battleConfigs.ts:531-543`）对所有 ally 单位调用链：
```
units.map → standardizePartyBattleUnit → PARTY_BATTLE_STATS['selin'] → hp:36
```
同时 `standardizePartyBattleUnit` 会过滤旧 `HPxx/ACxx` traits 文本并替换。**运行时瑟琳始终 36HP**。
