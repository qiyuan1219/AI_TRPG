## 一、快速入门

### 基本操作
- **点击屏幕** → 推进对话
- **行动阶段** → 点击推荐行动或输入框自由输入 → 点击"执行"
- **带【六维DC】标签的行动** → 会触发D20骰子检定
- **骰子检定**：D20 + 属性加值 + 熟练加值 ≥ DC 即成功。D20=20大成功，D20=1大失败

### 六维属性速查

| 六维 | 相关行动 |
|------|---------|
| **力量** | 正面迎击、破门、运动 |
| **敏捷** | 闪避、巧手、潜行 |
| **体质** | 抵抗毒素、喝酒、疲劳 |
| **感知** | 观察、生存、医疗、察觉、自然、洞悉 |
| **智力** | 调查、奥秘、分析 |
| **魅力** | 说服、交涉、暗号 |

### 3. 回声酒馆 · 快艇骰子

触发词：`前往回声酒馆` / `去酒馆` / `找萨洛`

**⚠ 进入前必须阅读5步规则教程**（强制，读完才能玩）

**游戏规则**：
- 每局你和萨洛各5骰，可重投3次
- 牌型从低到高：散点→一对→两对→三同→葫芦→四同→大顺→五同

**瑟琳技能**（每场游戏各限1次）：
- **透视**（智力DC10）：看萨洛部分骰面（成功越多看得越多）
- **说服**（魅力DC13）：增加本局重投次数（+1或+2）

**胜负奖励**：

| 结果 | 情报 | 额外 |
|------|------|------|
| ≥2胜（大胜） | 三人详细情报 | +100G金币 + 云苓线索 |
| ≥1胜（小胜） | 三人详细情报 | 无额外 |
| 0胜 | 三人基础情报 | 可花50G购买 |

**云苓线索**（仅高胜局）：黑市深处药剂商，有针对深层污染的药剂。

```
                    ┌─ 帮助莱因 ───┬─ 稳定核心 → 守门者仍在（偏好结局）
                    │              └─ 破坏核心 → 带伤者穿门（高风险）

                    ├─ 无视莱因 ───┬─ 稳定核心 → 冷静的远征（冷酷稳定）
```

**全收集**：先完成所有4条支线 → 帮助莱因 → 稳定核心
