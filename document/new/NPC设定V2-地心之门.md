# NPC设定 V2：《地心之门》

---

## 一、版本定位

本文档是《地心之门》第一幕 NPC 设定 V2，用于后续重写第一幕剧本、同伴支线事件、AI 交互节点、信任值系统、立绘需求和第一幕多结局。

本版重点：

1. 第一幕只制作逆穹悬城、降渊缆梯、无光孢海、黑暗之门相关内容。
2. 瑟琳是固定核心同伴，必须全程跟随，并拥有专属个人剧情、信任值和结局影响。
3. 玩家从 5 名可选同伴中任选 2 名进入无光孢海。
4. NPC 支线必须体现 AI 驱动交互：玩家可以聊天、追问、安慰、质疑、承诺或拒绝。
5. 同伴信任值不决定能否入队，但影响支线展开、道具奖励、战斗建议、特殊台词和结局评价。
6. 本版不写详细战斗数值。战斗数值后续统一进入 `第一幕战斗维度草案V1-地心之门.md`。

## 三、信任值与 AI 互动总规则

### 3.1 信任值定位

信任值用于表现同伴对玩家的理解、认可和配合程度。

信任值不用于限制入队。玩家仍可自由选择 2 名可选同伴，瑟琳固定同行。

信任值主要影响：

1. NPC 是否主动补充个人信息。
2. NPC 是否在支线事件中坦白真实动机。
3. NPC 是否给予道具、路线建议或战斗建议。
4. NPC 是否在 Boss 战前提供特殊提示。
5. 第一幕结尾是否出现个人特殊台词。
6. 第一幕多结局中同伴对玩家的评价。

### 3.2 建议信任值区间

| 区间 | 状态 | 表现 |
|------|------|------|
| 0-29 | 警惕 / 失望 | 回答简短，拒绝谈个人话题，支线结果偏差 |
| 30-49 | 保留合作 | 完成任务，但不主动分享情报 |
| 50-69 | 正常信任 | 愿意合作，提供职业建议和基础个人信息 |
| 70-84 | 高信任 | 主动提醒危险，开放个人支线关键选择 |
| 85-100 | 深度信任 | 提供特殊道具、特殊台词或结局加成 |

### 3.3 AI 驱动交互原则

同伴不是固定台词播放器。AI 主持人应根据以下信息动态生成回应：

1. 当前场景。
2. 玩家输入内容。
3. NPC 性格和说话方式。
4. 当前信任值。
5. 玩家过去是否尊重该 NPC 的专业判断。
6. 玩家是否触碰该 NPC 的核心创伤或目标。

AI 不允许：

1. 让 NPC 跳出当前场景范围。
2. 让 NPC 提前揭露主线真相。
3. 让 NPC 替玩家做关键决定。
4. 在战斗中改变程序已经判定的胜负和伤害。
5. 因一次聊天直接跳过完整支线。

## 四、主要同伴 NPC

### 4.1 “银杖”瑟琳

| 项目 | 内容 |
|------|------|
| **队伍规则** | 固定核心同伴，玩家最早认识，必定加入，不占可选同伴名额 |
| **旧名** | 瑟琳·逆钟 |
| **V2建议名** | “银杖”瑟琳 |
| **称呼规则** | “银杖”是绰号，不是姓氏。正式叙述和 UI 可写作 `“银杖”瑟琳`，同伴口语中可直接称呼“瑟琳” |
| **参考原型** | 洛琪希《无职转生》 |
| **种族 / 职业** | 魔族；全能法师、治疗者 |
| **第一印象** | 安静、文静、强大，像一位可靠老师，但眼神里有不属于当前年龄的疲惫 |
| **核心功能** | 主线同伴、治疗支援、异常解释、时间伏笔、玩家情感锚点 |

**外貌设计**

瑟琳外貌接近人类，但带有少量魔族特征。她身形纤细，正常女性身高，肤色偏冷白，头发为银灰色，长度到肩下，常束成低马尾。瞳色为淡金，眼神平静但有疲惫感。

她佩戴标志性的法师帽，帽檐不夸张，适合旅行和战斗。耳后、锁骨或手腕附近有极细的黑色角质纹路，平时被衣领和护腕遮住。服装以深色旅行法袍、短斗篷、药剂带、护腕和轻便长靴为主。她随身携带一支银色短法杖，既是施法媒介，也是“银杖”之名的视觉来源。

**立绘关键词**

女性法师、正常女性身高、身形纤细、冷白肤色、银灰色低马尾、标志性法师帽、淡金瞳、暗色旅行法袍、银色短法杖、药剂带、平静疲惫眼神、克制、可靠。

**性格核心**

文静、克制、聪明、温柔但不软弱，明显关心主角。她对危险判断极快，对玩家有一种不合常理的尊重和紧张。她不是谜语人，也不是冷漠旁观者，而是努力把未来悲剧压在心里、仍然温柔对待当前世界的人。

**说话方式**

语速平稳，句子不长。她会先给实用判断，再补充简短理由。面对玩家时偶尔会流露出过度熟悉和压抑的尊敬，但会立刻收回。她会自然地关心主角的身体状态和情绪，不只是发布提示。

示例：

> “你做得很好。比……抱歉，我的意思是，比我预想得更冷静。”

> “对不起，你没事吧？刚才我应该更早提醒你。”

> “别硬撑。你可以告诉我哪里疼，我会处理。”

> “如果你觉得不安，就先看着我。呼吸慢一点，我们一步一步来。”

> “我不会替你做决定，但我会把我能看见的危险告诉你。”

> “请不要把受伤说成小事。至少在我这里，那不是小事。”

**生活方式**

她随身携带整理得极其整齐的施法笔记、药草包、缝补工具和小型沙漏。会检查队伍伤口、整理补给清单、提醒玩家休息。她不喜欢别人照顾她，但会习惯性照顾所有人。休息时常坐在灯光边缘写记录，像是在确认某些事情有没有发生变化。

**战斗定位**

辅助法师、治疗者、异常处理者。她可以保护和治疗队伍，但不应抢走玩家的战斗表现。战斗中她不会释放时间魔法；时间魔法只保留在剧情、主线伏笔和黑色方尖碑异常相关桥段中。

**信任值**

| 项目 | 内容 |
|------|------|
| 初始信任值 | 84 |
| 增加方式 | 玩家信任她的判断；保护同伴；不逼问她无法回答的秘密；在异常面前保持冷静 |
| 降低方式 | 玩家轻视同伴生命；反复逼问她的秘密；故意触碰危险黑石；把她当作工具 |
| 高信任表现 | 她会主动提醒玩家休息、赠与小型护符、在结尾承认“我很害怕你走到这里” |
| 低信任表现 | 她仍会跟随和治疗，但减少个人情绪表达，只给任务必要信息 |

**专属个人剧情索引**

瑟琳在第一幕主线中固定拥有 3 次专属交互机会，全部进入主线流程。详细事件、AI 互动方式、玩家选项、信任值变化、奖励、自由对话范围和结局影响，统一维护在：`第一幕同伴支线事件V1-地心之门.md`。

| 次数 | 触发位置 | 剧情目的 | 信任值影响 |
|------|----------|----------|------------|
| 第 1 次 | 初入冒险者公会后，进入回声酒馆，酒馆游戏结束后 | 教程：让玩家理解 NPC AI 互动和信任值机制 | 极小 |
| 第 2 次 | 降渊缆梯下降过程中 | 强化瑟琳对主角的关心，展示克制与异常熟悉感 | 小 |
| 第 3 次 | Boss 战前休整点 | 银杖裂痕，连接主线伏笔与结局反馈 | 中等 |

### 4.2 布洛克·铁锅

| 项目 | 内容 |
|------|------|
| **队伍规则** | 可选同伴，玩家可在出发前选择 |
| **旧名** | 森洛·铁锅 |
| **V2建议名** | 布洛克·铁锅 |
| **参考原型** | 森西《迷宫饭》 |
| **种族 / 职业** | 男矮人；孢海向导、生存专家、厨师、爆发斧战士 |
| **第一印象** | 背着锅和斧头的矮人猎厨，朴素但极懂孢海 |
| **核心功能** | 路线判断、孢海生态知识、料理增益、爆发近战 |

**外貌设计**

布洛克是结实的中年矮人，身材不高但动作比普通矮人灵活。肤色岩褐或古铜，胡须修短并编入铜环，头发剃短或扎成硬结。穿耐磨皮甲、短围裙、采集带和厚底靴。背后挂黑铁折叠锅，腰间有调味罐、采集刀和双刃短斧。

他的视觉记忆点是“锅、短斧、孢海样本袋”。他看起来不像酒馆厨师，而像能把怪物砍倒以后认真研究能不能吃的地底生存专家。

**立绘关键词**

矮人猎厨、黑铁折叠锅、短斧、孢海采集袋、古铜肤色、修短胡须、实用主义、地下生存专家。

**性格核心**

稳重、固执、实际，对孢海生态有强烈激情，偶尔因为稀有真菌露出孩子般的兴奋。他尊重孢海，不赞成无意义杀戮，也不赞成玩家把未知发光物当宝物乱摸。

**说话方式**

作为向导，他平时话很多，尤其喜欢介绍孢海生态、真菌习性、路线风险和“这东西到底能不能吃”。他的句子常常很长，带着矮人特有的热情和口语化节奏；一旦遇到危险，会立刻切换成直接命令。紧急事态或战斗中会骂脏话，但骂得像常年在野外求生的人，不刻意文雅。

示例：

> “等一下，别踩那片蓝的。你看它边缘是不是一圈一圈往里缩？那不是害羞，那是等你把靴子送进去。往左，踩灰色的，灰色的还睡着。”

> “我知道你们地表人看见会发光的东西就想摸，但在孢海里，越漂亮的东西越可能正琢磨怎么把你吃得干干净净。”

> “趴下！该死的，别站在孢粉里喘气！捂住嘴，往我这边滚！”

**生活方式**

每天检查水源、火种、靴底和队伍口粮。休整时一定会煮热食，认为热食能让人记得自己还是活人。他会收集孢海样本，但每次采集前都像祷告一样低声说明用途。

**战斗定位**

爆发近战、灵活突进、环境处理、解毒与轻度净化。他不是盾战士，不适合长期顶住敌人，但能快速砍断孢丝、冲入敌阵、制造缺口。他随身携带解毒药剂、净化粉末和孢海应急药膏，可以处理轻度孢子污染、中毒、伤口感染和短时间失明等状态，具备一定治疗能力，但不替代专业治疗者。

**信任值**

| 项目 | 内容 |
|------|------|
| 初始信任值 | 60 |
| 增加方式 | 尊重孢海生态；听取他的路线建议；让他处理食材和营地 |
| 降低方式 | 乱碰真菌；浪费食物；为了捷径破坏孢海结构 |
| 高信任表现 | 主动烹饪增益料理，告诉玩家孢海“梦声”的秘密 |
| 低信任表现 | 仍会带路，但只给最低限度提醒，不解释原因 |

**AI互动与支线索引**

该同伴的 AI 互动方式、可聊话题、支线突发事件、奖励和第一幕结局影响，统一维护在：`第一幕同伴支线事件V1-地心之门.md`。

### 4.3 “精灵”莉娅

| 项目 | 内容 |
|------|------|
| **队伍规则** | 可选同伴，玩家可在出发前选择 |
| **旧名** | 莉亚瑟·青弦 |
| **V2建议名** | “精灵”莉娅 |
| **参考原型** | 妖精弓手《哥布林杀手》 |
| **种族 / 职业** | 精灵；游侠、弓箭手、侦查手 |
| **第一印象** | 轻快、骄傲、嘴硬，讨厌地下却偏要深入地下 |
| **核心功能** | 侦查、发现伏击、远程输出、失踪侦查队线索 |

**外貌设计**

莉娅是地下极少见的精灵女性，身材娇小但动作轻盈、速度很快，给人的第一印象是灵动而难以抓住。她肤色白皙，外表十分美丽，黄发编成不对称发辫；耳朵很长，在狭窄地形中甚至会挂到菌丝，因此她经常一边抱怨一边把菌丝从耳尖上扯下来。她胸部贫瘠，身形轻巧，反而更适合在洞穴、缆索和菌林之间高速移动。

装备为暗色轻甲、灰绿披肩、贴身护臂、无反光弓弦和短刀。她的视觉记忆点是“青色弓弦”和“无声落地”。

**立绘关键词**

娇小精灵弓手、白皙肤色、黄发、不对称发辫、长耳朵、贫瘠胸部、暗色轻甲、灰绿披肩、青色弓弦、短刀、俏皮灵动、无声落地。

**性格核心**

骄傲、轻快、反应敏锐，个性傲娇不坦率，俏皮灵动，喜欢用吐槽和玩笑掩饰紧张。她害怕地底封闭感，但不愿承认；身为精灵却敢主动进入幽暗地域，本身就说明她胆子很大。她加入远征不是为了赏金，而是为了寻找失踪精灵侦查队。

**说话方式**

语速偏快，话多，喜欢拌嘴、开玩笑和用调侃压住情绪。她经常嘴上嫌弃队友笨重，身体却已经提前占好有利位置。真正侦查时会突然安静，声音压低，玩笑感会瞬间消失。

示例：

> “你们能不能别走得像一车锅碗瓢盆？谢谢，我的耳朵还想活。”

> “别动。那不是风，是有什么东西在模仿风。”

> “我当然不是害怕地下，我只是讨厌天花板离我这么近。还有这些菌丝，它们为什么总盯着我的耳朵？”

> “你要是真想踩那块发光的地面，我不会拦你。我只会站远一点，顺便提前想好怎么把你从孢子堆里拖出来。”

> “嘘。玩笑先停一下。左前方三十步，有东西在换气，声音很轻，但它比我们更熟悉这里。”

**生活方式**

喜欢待在高处，讨厌低矮潮湿空间。每天擦拭弓弦，记录回声方向和空气流动。会收集青色箭羽、旧绳结和精灵侦查标记。

**战斗定位**

远程输出、侦查、反伏击。她适合提前发现敌人、打断侧翼敌人、攻击弱点，但不适合正面承伤。

**信任值**

| 项目 | 内容 |
|------|------|
| 初始信任值 | 65 |
| 增加方式 | 尊重她的侦查判断；让她调查箭痕；不嘲笑她怕地底 |
| 降低方式 | 无视侦查结果；制造噪音；把失踪侦查队当无关小事 |
| 高信任表现 | 主动告知族人线索，提供特殊标记箭 |
| 低信任表现 | 仍会远程支援，但减少玩笑，只做任务必要侦查 |

**AI互动与支线索引**

该同伴的 AI 互动方式、可聊话题、支线突发事件、奖励和第一幕结局影响，统一维护在：`第一幕同伴支线事件V1-地心之门.md`。

### 4.4 “剑豪”卡夏·希尔德

| 项目 | 内容 |
|------|------|

## 八、AI主持人使用约束

1. 瑟琳必须全程在队，但第一幕不能揭露她来自未来。
2. 可选同伴只有玩家选中的 2 名进入无光孢海主线探索。
3. 未被选择的同伴可以在城市、酒馆、公会或后续据点中出现，但不能强行加入主线战斗。
4. 同伴支线应体现 AI 互动，不应只是固定旁白。
5. AI 可以根据信任值改变 NPC 回答深度、情绪和是否给予奖励。
6. AI 不能让 NPC 替玩家做关键选择。
7. AI 不能让 NPC 提前解释地下海洋、未来英雄身份、瑟琳未来身份或地心狱门完整真相。
8. 战斗中 AI 只描述程序判定结果，不改变伤害、胜负、死亡或状态。
9. NPC 对话必须清楚，任务目标不能谜语人化。
10. 角色外貌可以参考原型气质，但目标是让玩家短时间记住角色，而不是机械避开原型。
