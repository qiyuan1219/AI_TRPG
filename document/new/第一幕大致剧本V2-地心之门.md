# 第一幕大致剧本 V2：《地心之门》

---

## 一、剧本定位

本文档是《地心之门》第一幕正式主流程剧本 V2，用于交给队友理解玩家实际游玩时会经历什么，以及每个节点如何对接当前 DEMO 已实现的 AI 主持、检定、小游戏、自由对话、信任值和回合制战斗。

本文档负责：

1. 串联第一幕主线流程。
2. 标明每个场景的交互类型。
3. 给出关键 NPC 出场、功能和少量台词示例。
4. 标明哪里进入小游戏、自由对话、检定、战斗、同伴支线、Boss 和结局。
5. 给后续开发明确“此处调用哪个系统 / 哪个文档”。

本文档不负责：

1. 不复写完整 NPC 设定。
2. 不复写完整同伴支线。
3. 不复写完整 Boss 与结局设计。
4. 不写战斗六维、伤害倍率、技能冷却和敌人数值。
5. 不展开第二幕之后剧情。

当前项目只制作第一幕，因此本文档必须保证第一幕本身完整、清晰、可玩。

## 四、主要场景剧本

### 场景1：玩家创建角色

| 项目 | 内容 |
|------|------|
| 场景目标 | 让玩家确认“来自地表的冒险者”身份，并选择职业方向 |
| 交互类型 | 固定引导、玩家选择 |
| 场景地点 | 游戏开场界面 / 角色创建界面 |
| 出场 NPC | 无 |
| GM/KP开场描述 | 地表边境近年不断遭到地下魔物袭击。旧矿道、废井、裂谷和墓穴里出现了不属于地表的爪痕。你接到逆穹悬城冒险者公会的委托，被送往幽暗地域入口。 |
| 玩家可行动方向 | 选择职业；确认姓名；确认基础战斗风格；进入逆穹悬城 |
| 可用检定 | 无正式检定 |
| AI可补写范围 | 可根据玩家职业补充一两句地表背景，例如战士护送商队、游侠追踪魔物、法师调查异常 |
| AI禁止内容 | 不要提前说明玩家未来英雄身份；不要解释地心狱门真相 |
| 信任值 / 道具 / 线索变化 | 初始无变化 |
| 进入下一节点条件 | 玩家确认职业与身份 |
| 相关详细文档 | 世界观底盘见 `世界观文档V1-地心之门.md` |

可选职业建议：战士、游侠、法师、牧师、盗贼、圣武士、术士等。此处只做开局定位，不写复杂数值。

### 场景2：初入逆穹悬城

| 项目 | 内容 |
|------|------|
| 场景目标 | 用第一视觉冲击告诉玩家：逆穹悬城不是普通新手村，而是幽暗地域前线奇迹工程 |
| 交互类型 | 固定剧情、AI续写、观察类检定 |
| 场景地点 | 逆穹悬城入口、倒挂街区、通往公会的主缆街 |
| 出场 NPC | 黑缆守卫队，少量城市居民 |
| GM/KP开场描述 | 你抬头时，城市在头顶展开。街道、塔楼、神殿和工坊倒挂在巨大洞穴的穹顶上，秘银主缆像冻结的瀑布垂向深渊。远处中央深井下方，蓝绿色幽光在黑暗里起伏，仿佛洞穴底部沉睡着一片会呼吸的星云。 |
| 关键NPC台词示例 | 黑缆守卫：“地表来的？别盯着下面看太久，第一次有人看吐在通行证上。” |
| 玩家可行动方向 | 观察城市结构；询问守卫；查看下方深井；前往冒险者公会；留意居民种族 |
| 可用检定 | 感知：发现城市防御机关；调查：理解主缆与重力符文；历史 / 奥秘：判断这类工程不可能由单一种族完成 |
| AI可补写范围 | 可描写倒挂城市的市井、缆道、防御弩台、居民反应 |
| AI禁止内容 | 不要让城市自由闲逛过长；不要提前引出黑暗之门后方反转 |
| 信任值 / 道具 / 线索变化 | 玩家可获得基础线索：逆穹悬城是前线中转站，地下魔物上涌已经影响城市 |
| 进入下一节点条件 | 玩家前往公会路线上遇见瑟琳 |
| 相关详细文档 | `第一幕设定文档V1-地心之门.md` |

设计重点：这个场景应该给玩家强烈记忆点。可以让玩家有短暂自由观察，但不要展开七八个城市地点，主线要尽快引向瑟琳和公会。

### 场景3：“银杖”瑟琳初登场

| 项目 | 内容 |
|------|------|
| 场景目标 | 让瑟琳最早认识玩家，并自然固定入队 |
| 交互类型 | 固定剧情、NPC对话、轻量自由输入 |
| 场景地点 | 逆穹悬城主缆街，靠近公会方向 |
| 出场 NPC | “银杖”瑟琳，黑缆守卫队 |
| GM/KP开场描述 | 公会钟声从倒挂塔楼里传来。人流被一队黑缆守卫分开，你看见一名戴着法师帽的银灰发女性站在路边，手中短银杖轻轻点在地面。她像已经等了你很久，却又在你看向她时把那种熟悉感收回眼底。 |
| 关键NPC台词示例 | 瑟琳：“你就是从地表来的冒险者吧。比我想象中……来得更早。” |
| 玩家可行动方向 | 询问她是谁；询问公会位置；观察她的法杖和神情；直接同行前往公会 |
| 可用检定 | 洞察：察觉她对玩家有不合常理的关注；奥秘：判断她是强大施法者；感知：发现她一直在留意玩家周围危险 |
| AI可补写范围 | 可表现瑟琳文静、克制、关心主角、略有疲惫感 |
| AI禁止内容 | 不要揭露她来自未来；不要让她长篇解释时间魔法；不要让她替玩家决定任务 |
| 信任值 / 道具 / 线索变化 | 瑟琳初始信任值 84；固定加入队伍，不占可选同伴名额 |
| 进入下一节点条件 | 玩家与瑟琳一同行动，附近发生教学战斗 |
| 相关详细文档 | `NPC设定V2-地心之门.md` |

瑟琳加入方式：她可以说明自己受公会邀请同行，负责法术支援、治疗和异常处理。她不需要请求玩家批准，但要让玩家知道她会听从队伍决策。

瑟琳补充台词：

> “我会同行。公会文书上写的是法术支援和伤员处理，这两个我都能做。”

> “如果你受伤，请直接告诉我。逞强会让治疗变麻烦，也会让我担心。”

### 场景4：第一次冲突：教学战斗

| 项目 | 内容 |
|------|------|
| 场景目标 | 用极低难度战斗教学攻击、闪避、队友协助、治疗和 AI 战斗描述 |
| 交互类型 | 固定触发、回合制战斗描述 |

| GM/KP开场描述 | 一只货箱突然从缆车上震落，木板炸开，里面蜷缩的不是货物，而是几只被孢粉刺激到发狂的小型地下魔物。它们撞翻灯架，沿着倒挂街面向人群扑来。 |
| 关键NPC台词示例 | 瑟琳：“别后退到缆边。先解决最近的那只，我会看住你的伤口。” |
| 玩家可行动方向 | 攻击敌人；保护路人；躲避扑击；观察敌人弱点；接受瑟琳治疗 |
| 可用检定 | 此处主要进入战斗系统；可在战前用感知判断敌人数量 |

| 进入下一节点条件 | 教学敌人被击败，黑缆守卫控制现场 |

胜利后处理：瑟琳可以治疗轻伤；守卫感谢玩家但语气严肃，强调最近这类事件变多。此处自然引向冒险者公会。

## 七、黑市讲价小游戏说明

黑市讲价小游戏位于出发前准备阶段，是主线剧情，不是可跳过的普通商店。

基础规则：

1. NPC 为“黑市商人”奥兰·爵。
2. 玩家与奥兰进行 5 轮讲价。
3. 每轮玩家选择话术并触发检定。
4. AI 根据检定结果返回奥兰的反应文本和价格调整。
5. 第 5 轮后显示最终讲价结果、最终价格、购得物品、附赠品或欠账风险。
6. 该环节结束后，队伍前往降渊缆梯。

话术方向可包括：礼貌压价、展示公会委托、套近乎、识货反驳、威胁揭发、情报交换、接受欠账。

限制：

1. 不要让奥兰成为主线幕后黑手。
2. 不要让讲价超过 5 轮。
3. 不要让 AI 擅自生成未配置强力道具。
4. 不要让讲价变成长篇支线。
5. 凯娅若同行，可以表现出熟悉黑市规则，但她的完整黑市背景仍留到支线文件。

## 九、AI主持人全局约束

1. 玩家始终是主角，NPC 不能抢走关键选择和最终胜利。
2. “银杖”瑟琳固定同行，不占可选同伴名额。
3. 瑟琳战斗中是辅助法师和治疗者，不释放战斗用时间魔法。
4. 瑟琳强力时间魔法只在 Boss 战小队团灭坏结局“逆时归零”中触发。
5. 第一幕不能揭露瑟琳来自未来。
6. 第一幕不能提前揭露玩家未来英雄身份。
7. 黑暗之门开启前，禁止用明确词汇明示门后反转。
8. 第一幕结尾才揭示：黑暗之门后不是地底堡垒，而是地下海洋。
9. 不要完整解释地心狱门、阿弗纳斯、黑色方尖碑技术和地底堡垒失联真相。
10. “断缆”赫尔曼和“公会任务官”米娜必须清楚说明任务，不要谜语人。
11. “士兵”莱因可以精神崩溃、逻辑混乱，但不能说出结尾反转。
12. 纯粹 NPC 只提供功能信息，不展开复杂个人线。
13. 玩家每个主要场景都应有明确行动选择。
14. AI 不能决定战斗胜负、伤害、死亡或状态，只能描述程序结果。
15. 自由对话期间默认不改变信任值，防止刷数值。
16. 同伴支线和信任值不改变第一幕结局分支，只影响奖励、建议、台词和反馈。
17. 只使用新版命名；旧版姓名不得进入剧本正文。
