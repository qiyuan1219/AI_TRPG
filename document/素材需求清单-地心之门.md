# 素材需求清单 V2：《地心之门》第一幕

## 一、统一美术风格规范

| 维度 | 规范 |
|------|------|
| **画风** | 日式二次元风格，赛璐珞/平涂上色，清晰干净的线条，柔和阴影。参考动画电影质感，接近《迷宫饭》《来自深渊》《无职转生》等作品的高质量视觉。 |
| **色彩基准** | 主色：深蓝紫（`#1a1a3e`）、暗紫黑（`#0d0d1a`）、地底青绿荧光（`#5fb7a7`） |
| | 辅色：暖黄白（`#f5ecd8`）、菌丝蓝白（`#8accd8`）、孢子蓝绿（`#6de0c4`） |
| | 强调色：炼狱暗红（`#9c3f57`）、深金（`#d4a843`）、黑石暗紫（`#4a2080`） |
| **画面基调** | 暗色系为主，但保留二次元特有的高光/辉光效果（荧光、符文、魔法光圈）。幽暗地下环境 + 日式奇幻冒险气息。 |
| **场景构图** | 16:9 横版，1920×1080 WebP。底部 28% 留白给对话框叠加。 |
| **光照原则** | 无自然日光。所有光源来自：符文冷光、菌类荧光、魔力辉光、火把/冷光灯、时间魔法银色光。采用二次元的"发光图层/特效层"表现方式（叠加发光/色减淡图层）。 |
| **角色风格** | **剧情/对话时**：正比立绘（7-8头身），全身或半身，透明PNG。造型干净、有辨识度的二次元角色设计。 |
| | **战斗时**：Q版/2头身角色（Chibi/SD），保留正比立绘的核心服装和配色特征，简化细节，表情更夸张。PNG透明背景。 |
| **特效风格** | 二次元光效：发光粒子、星屑、魔法阵（圆形/六角形符文阵）、速度线、集中线。孢子尘埃用飘浮圆形软光点表现。 |
| **角色设计原则** | 每个角色参考指定原型人物的气质、画风和设计语言，但不是复制。保留原型人物的「氛围感」而非具体细节。 |

## 三、场景背景素材（P0 核心路径必经场景）

所有场景默认规格：**1920×1080, WebP, 16:9, 横版**

**风格统一说明**：所有场景画风为日式二次元背景，参考《来自深渊》的洞穴奇观表现力+《迷宫饭》的地下生态氛围+《无职转生》的异世界建筑质感。不是照片级写实，而是有动画电影质感的手绘/数字绘画背景。
