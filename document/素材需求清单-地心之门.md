# 素材需求清单 V1：《地心之门》第一幕

---

## 一、统一美术风格规范

| 维度 | 规范 |
|------|------|
| **风格主题** | 暗黑奇幻 × 视觉小说 UI × 幽暗地域地底美学 |
| **画风** | 半写实厚涂，色彩饱和但低明度，强调光影对比与荧光效果 |
| **色彩基准** | 主色：深靛蓝（`#152943`）、暗紫（`#15111b`）、地底青绿荧光（`#5fb7a7`） |
| | 辅色：羊皮纸暖白（`#f5ecd8`）、菌丝蓝白（`#8accd8`）、孢子蓝绿（`#6de0c4`） |
| | 强调色：炼狱暗红（`#9c3f57`）、深金（`#d4a843`）、黑石暗紫（`#4a2080`） |
| **场景构图** | 16:9 横版，底部 28% 留白给对话框 |
| **光照原则** | 幽暗地下无自然光，所有光源来自：符文冷光、菌类荧光、魔力辉光、火把/冷光灯 |
| **角色风格** | D&D 奇幻风格，差异化种族特征（矮人敦实、精灵修长、兽族灵敏、机械体块感） |
| **特效风格** | 粒子感孢子尘埃、蓝绿色荧光拖尾、紫黑色能量溢散、暖金色时间魔法辉光 |

## 十二、接入方式说明

当前项目架构中素材的接入方式：

1. **场景背景**：在 `index.css` 中为每个 `.scene-*` 类添加 `background-image: url('/assets/scenes/BG-XX.webp')`，保留现有渐变作为 fallback
2. **角色立绘**：在 `VisualNovelStage.tsx` 的对话框中，匹配当前说话人后显示对应立绘 `<img src="/assets/characters/CH-XX.png">`
3. **道具图标**：在 `CharacterPanel.tsx` 背包渲染时根据物品名匹配图标路径
4. **UI 面板**：替换 `index.css` 中面板背景为 `background-image: url('/assets/ui/...')`
5. **音频**：需新接入音频管理模块（如 Howler.js），在 `App.tsx` 中根据场景切换 BGM，在检定/战斗等事件中触发 SFX
6. **特效**：优先用 CSS/SVG 实现动画效果，WebM 作为备选方案
7. **战斗精灵**：当前用纯 CSS 几何图形，接入 PNG 立绘可替换 `.battle-sprite` 内部结构
