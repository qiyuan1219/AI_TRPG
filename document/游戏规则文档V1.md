# 游戏规则文档V1：《碎冠之影》D20系统

---

## 一、设计理念

基于D&D 5E简化，为AI-DK特化：
1. **D20核心**：所有检定投1D20 + 属性调整值
2. **战斗优先**：地城探索包含大量战斗遭遇
3. **简单透明**：HP/AC/属性直观，玩家能快速决策

---

## 二、属性系统

### 六项属性

| 属性 | 缩写 | 影响 | 建议范围 |
|------|------|------|---------|
| **力量** | STR | 近战攻击、负重、破门 | 8-18 |
| **敏捷** | DEX | 远程攻击、闪避、潜行、先攻 | 8-18 |
| **体质** | CON | HP上限、耐力、抗毒 | 8-18 |
| **智力** | INT | 法术攻击(法师)、知识、调查 | 8-18 |
| **感知** | WIS | 法术攻击(牧师)、察觉、生存 | 8-18 |
| **魅力** | CHA | 法术攻击(术士)、说服、威吓 | 8-18 |

### 调整值计算
```
属性值 → 调整值
8-9  → -1
10-11 → 0
12-13 → +1
14-15 → +2
16-17 → +3
18   → +4
```

### 职业预设（标准数组15,14,13,12,10,8分配）

| 职业 | STR | DEX | CON | INT | WIS | CHA | HP | AC |
|------|-----|-----|-----|-----|-----|-----|----|----|
| **战士** | 16(+3) | 13(+1) | 15(+2) | 10(0) | 12(+1) | 8(-1) | 30 | 18 |
| **游荡者** | 10(0) | 16(+3) | 14(+2) | 12(+1) | 13(+1) | 8(-1) | 26 | 15 |
| **法师** | 8(-1) | 13(+1) | 14(+2) | 16(+3) | 12(+1) | 10(0) | 20 | 13 |
| **牧师** | 13(+1) | 10(0) | 14(+2) | 12(+1) | 16(+3) | 8(-1) | 26 | 16 |
| **圣骑士** | 15(+2) | 10(0) | 13(+1) | 8(-1) | 12(+1) | 14(+2) | 28 | 18 |
| **自定义** | 自由分配标准数组 |

### HP计算
- 初始HP：职业基础 + 体质调整值
- 升级HP：每级+1d10+体质调整值（由DK自动处理）
- 短休恢复：消耗生命骰1d10+体质调整值
- 长休恢复：恢复全部HP

## 三、检定系统 D20

### 核心检定
```
投1D20 + 属性调整值 + 熟练加值 ≥ DC（难度等级） = 成功
```

| D20结果 | 效果 |
|---------|------|
| 20（大成功） | 自动成功，额外好处 |
| ≥ DC | 普通成功 |
| < DC | 失败 |
| 1（大失败） | 自动失败，额外惩罚 |

### 难度等级(DC)
| 难度 | DC | 示例 |
|------|-----|------|
| 极简单 | 5 | 在安静的房间听到脚步声 |
| 简单 | 10 | 撬一把普通锁 |
| 中等 | 13 | 翻越6尺石墙 |
| 困难 | 15 | 说服敌对NPC透露情报 |
| 极难 | 18 | 从崩塌的天花板下闪避 |
| 近乎不可能 | 22 | 徒手撕开铁门 |

### 对抗检定
当两个角色对抗时（如潜行vs察觉），双方投D20+调整值，比较结果。

### 检定触发时机（强制）
- 攻击敌人 → 攻击检定
- 闪避/躲避 → 敏捷豁免
- 搜索房间 → 智力检定
- 察觉陷阱 → 感知检定
- 说服/威吓/欺骗NPC → 魅力检定
- 每在地城中移动到一个新房间 → 潜行检定（或直接遭遇）
- 地城休息 → 感知检定设岗哨

## 四、战斗系统

### 战斗流程
```
1. 确定先攻：投D20+DEX调整值，由高到低行动
2. 每轮每人可做：1个动作 + 1个附赠动作 + 移动(30尺)
3. 动作选项：攻击、施法、使用物品、闪避、急救
4. 敌方回合由DK自动处理
```

### 攻击检定
```
投1D20 + 属性调整值(近战STR/远程DEX) + 熟练加值 ≥ 目标AC = 命中
命中后投伤害骰 + 属性调整值 = 最终伤害
```

### 伤害类型
| 武器 | 伤害 |
|------|------|
| 徒手 | 1+STR |
| 匕首/短剑 | 1d4+DEX |
| 长剑/战斧 | 1d8+STR |
| 巨剑/巨斧 | 2d6+STR |
| 短弓/弩 | 1d6+DEX |
| 长弓 | 1d8+DEX |

### 法术攻击
| 法术 | 伤害 | 消耗 |
|------|------|------|
| 火焰箭 | 1d10 | 戏法(无限) |
| 魔法飞弹 | 3d4+3 | 1级法术位 |
| 治疗术 | 1d8+WIS | 1级法术位 |
| 火球术 | 8d6 | 3级法术位 |
| 光亮术 | 驱散黑暗 | 戏法 |
| 护盾术 | AC+5一回合 | 1级法术位 |

### 死亡豁免
HP归零→倒地状态。每轮投D20：
- ≥10记一次成功，<10记一次失败
- 3次成功→稳定（1HP），3次失败→死亡
- 投出20→立即恢复1HP
- 投出1→计两次失败

## 五、成长与升级

### 升级条件
每击败一层Boss，所有玩家升级1级（从3级开始，最高7级）。

### 升级奖励
- HP增加1d10+CON调整值
- 熟练加值随等级提升（3级+2, 5级+3, 7级+4）
- 战士4级选择：力量+2 或 力量+1+敏捷+1
- 法师/牧师获得新法术
- 游荡者偷袭伤害提升

## 七、同伴好感度

0-100信任值，影响：
- 是否分享秘密
- 战斗中是否会保护你
- 结局时是否存活

变化规则：
- 战斗中保护同伴+15
- 给同伴分金币+10
- 对同伴隐瞒情报-10
- 同伴倒地不救-30
