# NPC设定 V1：《碎冠之影》

> 统一模板：姓名 | 身份 | 种族职业 | 性格 | 秘密 | 目标 | 初始态度（0-100）| 可触发事件

---

## 一、王庭阵营

### 1. 伊瑟拉·星语（盟友/任务发布者）
| 项目 | 内容 |
|------|------|
| **姓名** | 伊瑟拉·星语 |
| **身份** | 高等精灵，王国大法师，摄政议会成员 |
| **性格** | 睿智、冷静、说话爱拐弯抹角、对"命运"有执念 |
| **秘密** | 她曾是阿尔德温零世的恋人。两百年前她亲手将碎冠之心交给零世，血契的诅咒有她一半责任。她活了217年，一直在找解除血契的方法 |
| **目标** | 解除血契，救回国王，赎清自己两百年前的罪 |
| **初始态度** | 65（需要冒险者，但一开始不会全盘托出） |
| **可触发事件** | ①信任>80时坦白零世的往事 ②在地城B4层遇到零世的幻影时触发独白 ③结局时可以选择代替她承受代价 |
| **战斗能力** | AC15 HP45 法术位3级。掌握光亮术、魔法飞弹、火球术 |

### 2. 雷恩·灰鬃（潜在反对者）
| 项目 | 内容 |
|------|------|
| **姓名** | 雷恩·灰鬃 |
| **身份** | 人类，王国骑士团团长 |
| **性格** | 务实、强硬、讨厌魔法和不确定性 |
| **秘密** | 他已秘密效忠公主塞琳娜，准备在国王死后拥立公主登基。他认为这样王国才能稳定 |
| **目标** | 维持王国稳定，哪怕代价是国王死 |
| **初始态度** | 40（认为外来冒险者只会添乱） |
| **可触发事件** | ①玩家表现英勇后态度+15 ②如果揭发他和公主的阴谋，他会反叛 ③如果玩家说服他"国王可以救"，可能倒戈 |

### 3. 塞琳娜公主（隐藏反派）
| 项目 | 内容 |
|------|------|
| **姓名** | 塞琳娜·阿尔德温 |
| **身份** | 人类，国王阿尔德温三世之妹 |
| **性格** | 表面温柔体贴，内心冷酷且野心勃勃 |
| **秘密** | 她不是想篡位那么简单——她已与暗影教会达成协议：血契完成后，深渊会让她成为新任女王 |
| **目标** | 确保血契完成，哥哥死亡，自己登基 |
| **初始态度** | 25（表面友好，送玩家小礼物，实际在误导方向） |
| **可触发事件** | ①送玩家一件"护身符"→实际是定位追踪器，会让每日遭遇变多 ②在地城B3层会暗中派人阻碍 ③最终揭露时她会在B5层入口拦截玩家 |

## 二、冒险者同伴（可选同行的NPC）

### 4. 铁锤格鲁姆（战士同伴）
| 项目 | 内容 |
|------|------|
| **姓名** | 铁锤格鲁姆 |
| **身份** | 矮人，冒险者公会副会长，6级战士 |
| **性格** | 豪爽、话多、好酒、见到金币眼睛发光，但讲义气 |
| **秘密** | 他欠商人联盟一大笔钱，急需赏金。但他从不坑同伴 |
| **目标** | 赚够钱还债，顺便扬名立万 |
| **初始态度** | 60（对所有人友好，有钱赚更友好） |
| **可触发事件** | ①请他喝酒→态度+10 ②在战斗中保护他→态度+20 ③帮他还债→成为永久忠诚同伴 |
| **战斗** | AC18 HP52 主力近战输出，会嘲讽吸引火力 |

### 5. 影刃丽莎（游荡者同伴）
| 项目 | 内容 |
|------|------|
| **姓名** | 影刃丽莎 |
| **身份** | 半精灵，冒险者公会情报员，5级游荡者 |
| **性格** | 精明、话少、观察力极强、偶尔冷笑话 |
| **秘密** | 她曾是暗影教会的成员，因拒绝刺杀目标而被驱逐。所以她知道教会的运作方式 |
| **目标** | 摧毁暗影教会，为自己复仇 |
| **初始态度** | 45（保持观察，不容易信任） |
| **可触发事件** | ①信任>70时告知暗影教会的秘密入口 ②在B3层触发"指路"特殊事件 ③与暗影教会对决时获得额外伤害加成 |
| **战斗** | AC16 HP38 侦查/解除陷阱/偷袭 |

### 6. 学徒塔莉亚（法师同伴）
| 项目 | 内容 |
|------|------|
| **姓名** | 塔莉亚·焰痕 |
| **身份** | 人类，伊瑟拉的学徒，3级法师 |
| **性格** | 崇拜强者、好奇心旺盛、法术偶尔失控 |
| **秘密** | 她有1/4龙族血统，情绪激动时会不自主喷出火星。她父母死于灰烬之裔的袭击 |
| **目标** | 向灰烬之裔复仇，成为像伊瑟拉一样的大法师 |
| **初始态度** | 75（崇拜冒险者，容易信任） |
| **可触发事件** | ①在地城中触发"龙血觉醒"→临时获得火焰吐息能力 ②对灰烬之王有额外伤害 ③可能因为冲动触发陷阱 |
| **战斗** | AC13 HP24 法术位2级。掌握火焰箭、法师护甲 |

## 三、暗影教会

### 7. 莫德雷德主教（主反派）
| 项目 | 内容 |
|------|------|
| **姓名** | 莫德雷德 |
| **身份** | 人类，神殿高级神官，暗影教会领袖 |
| **性格** | 温和、有魅力、擅长操控人心、深信自己在做"正确的事" |
| **秘密** | 他是阿尔德温零世的直系后裔（零世入赘前的私生子一脉）。血契完成后他将成为深渊在人间的代理人 |
| **目标** | 完成血契，获得深渊之力 |
| **初始态度** | 30（表面友善，每次治疗后都在玩家身上留下监视印记） |
| **可触发事件** | ①接受三次神殿治疗→被标记→地城遭遇增多20% ②揭穿他的身份在B4层触发额外对话 ③最终可以选择说服他放弃（极难，魅力检定-20） |

## 四、地城Boss（灰烬之裔五位近卫）

### 8. 被腐化的圣堂骑士（B1 Boss）
| 项目 | 内容 |
|------|------|
| **姓名** | 塞德里克·圣盾 |
| **身份** | 零世近卫队长，圣骑士，灵魂被灰烬腐蚀 |
| **性格** | 痛苦、矛盾、在被腐蚀边缘挣扎 |
| **秘密** | 他是唯一一个在血契签订时提出反对的近卫。但他的反对被零世无视 |
| **目标** | 渴望被击败——他不想再作为灰烬之裔存在 |
| **特殊机制** | 战斗中偶尔失去攻击意愿，低语"杀了我" |

### 9. 疯癫的抄写员之魂（B2 Boss）
| 项目 | 内容 |
|------|------|
| **姓名** | 老抄写员奥图斯 |
| **身份** | 零世的御用法师，后成为修道院图书馆长 |
| **性格** | 疯癫、混乱、但内心某处保留着学者的理智 |
| **秘密** | 他记录下了血契的完整文本——就藏在书库的某本无标题书里 |
| **目标** | 被困在书的知识中，忘记了自我 |
| **特殊机制** | 玩家如果找到他的日记并念给他听→跳过战斗（智力检定） |
