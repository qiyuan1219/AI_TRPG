# 《碎冠之影》职业与队友技能体系 V2

> 基于 [DND战斗规则详解.md](./DND战斗规则详解.md) 全部机制设计，每个技能明确标注消耗的动作类型、掷骰公式、触发条件和连锁效果。

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **动作经济全覆盖** | 每个职业至少有 Action / Bonus Action / Reaction 各一个技能 |
| **精通系统绑定** | 战士/游荡者/圣骑士绑定武器精通特性 |
| **状态链明确** | 每个控制技能注明施加的状态及解除条件 |
| **优劣势清晰** | 每个增益/减益技能标注优势/劣势来源 |
| **随机性丰富** | 多用多面骰（d4/d6/d8/d10/d12）、暴击翻倍、抵抗/易伤 |

## 三、五种玩家职业

### 3.1 战士 —— 重装先锋

**定位**：前排坦克/物理输出，擅压制、格挡、破甲。

**属性**（标准数组 16,13,15,10,12,8）：STR 16(+3) | DEX 13(+1) | CON 15(+2) | INT 10(0) | WIS 12(+1) | CHA 8(-1)

**基础数据**：HP 30 | AC 18（板甲）| 移动速度 30尺 | 熟练加值 Lv3=+2

**武器精通槽位（2024新规）**：2个，长休后可选。绑定武器与精通：
- 长剑 → **Sap**（命中后目标下次攻击劣势）
- 战斧 → **Topple**（命中后目标 CON豁免否则倒地）
- 巨剑 → **Graze**（未命中仍造成STR调整值伤害）
- 长矛 → **Slow**（命中后目标速度-10尺）
- 战锤 → **Push**（命中后推10尺）

## 七、技能随机性设计

| 随机元素 | 体现 |
|----------|------|
| **D20暴击** | 所有攻击技能 D20=20 伤害骰翻倍 |
| **D20大失败** | D20=1 自动未命中 |
| **多面骰伤害** | d4(匕首/飞弹)、d6(短剑/偷袭)、d8(长剑/战锤/光耀)、d10(火焰箭/巨斧)、d12(巨斧)、2d6(巨剑/偷袭) |
| **豁免对抗** | 敌人投D20+调整值 vs 我方DC(8+属性+熟练) |
| **优劣势重投** | Vex命中→下击优势(2次取高)、倒地目标近战优势、中毒/目盲→劣势(2次取低) |
| **状态持续时间** | 目盲/束缚/倒地/恐慌通常1轮，专注法术最长1分钟 |
| **抗性掷骰** | 龙火护罩→选一种元素抗性；反射闪避→DEX豁免成功免伤 |
