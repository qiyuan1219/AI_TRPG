## 一、战斗总览

### 战斗结构

```
┌─────────────────────────────────────────────┐
│  1. 确定突袭（DM判定谁被突袭）                │
│  2. 确定位置（角色与敌人在哪）                │
│  3. 投先攻（决定行动顺序）                     │
│  4. 轮流行动（直到一方战败/逃跑）              │
│  5. 战斗结束                                 │
└─────────────────────────────────────────────┘
```

### 一轮（Round）与一回合（Turn）

| 概念 | 说明 |
|------|------|
| **一轮** | 所有战斗参与者各行动一次，约6秒游戏时间 |
| **一回合** | 单个角色在该轮中的行动时间 |

## 二、先攻与回合顺序

### 先攻检定

```
先攻值 = D20 + 敏捷调整值
```

### 顺序规则

1. 所有参与者投先攻，由高到低排序
2. 如果持平：PC优先于NPC；同类型则由DM决定
3. 先攻顺序在整个战斗中保持不变
4. **延迟行动（2024新规）**：玩家可以选择将自己的回合延迟到某个盟友之后，但必须在回合开始时声明

### 先攻交换（2024新规）

- 同一方的角色可以在第一轮开始前交换先攻值
- 一旦确定，战斗中不可再次交换

## 三、动作经济（Action Economy）

每回合每个角色拥有以下资源：

| 资源 | 数量 | 说明 |
|------|------|------|
| **动作（Action）** | 1个 | 主要行动 |
| **附赠动作（Bonus Action）** | 1个 | 额外快速行动 |
| **反应（Reaction）** | 1个/轮 | 在其他角色回合中触发 |
| **移动（Movement）** | - | 等于你的速度值 |
| **自由交互（Object Interaction）** | 1个 | 拔武器、开门等 |

### 动作选项

#### 【攻击 Attack】

进行一次近战或远程攻击。

#### 【施法 Cast a Spell】

施展一个施法时间为1动作的法术。

#### 【疾走 Dash】

本回合获得额外移动，等于你的速度值。

#### 【撤离 Disengage】

本回合移动不会触发借机攻击。

#### 【闪避 Dodge】

直到你的下一回合开始：
- 敌人对你攻击有**劣势**（Disadvantage）
- 你对敏捷豁免有**优势**（Advantage）

#### 【协助 Help】

协助一个盟友：
- **战斗协助**：盟友下次攻击目标有优势（需在5尺内）
- **技能协助**：盟友下次技能检定有优势

#### 【躲藏 Hide】

投DEX（潜行）检定 vs 敌人感知（察觉）。成功则获得**隐形状态**。

#### 【准备动作 Ready】

准备一个动作，设定触发条件。使用你的**反应**执行。

#### 【搜索 Search】

投感知（察觉）或智力（调查）检定寻找隐藏事物。

#### 【使用物件 Use an Object】

使用需要动作激活的魔法物品或特殊道具。

#### 【影响物件 Influence/Object Interaction】（2024新规）

- 拔/收武器：作为攻击动作的**一部分**（免费，每个攻击一次）
- 开关门、从背包取物：使用**自由交互**

---

### 附赠动作（Bonus Action）

只有当职业特性、专长或法术明确授予时才可使用。常见来源：

| 来源 | 附赠动作 |
|------|---------|
| 双武器战斗 | 副手攻击 |
| 战士：回气 | 恢复1d10+战士等级 HP |
| 游荡者：灵巧动作 | 疾走/撤离/躲藏 |
| 野蛮人：狂暴 | 进入狂暴状态 |
| 施法类法术 | 如治疗真言、灵体武器 |

---

### 反应（Reaction）

每轮1次，在你回合外使用。回合开始时刷新。

| 常见反应 | 触发条件 |
|----------|---------|
| **借机攻击** | 敌人离开触及范围 |
| **护盾术** | 被攻击命中 |
| **吸收元素** | 受到特定属性伤害 |
| **准备动作** | 预设条件满足 |
| **羽落术** | 坠落时 |

## 四、移动与位置

### 移动规则

- 可在动作前/后分段移动
- 可在多次攻击之间移动
- 可穿过非敌意生物（视为困难地形）
- **不能**穿过敌对生物（除非体型差距2级以上）

### 移动类型

| 类型 | 说明 |
|------|------|
| 步行 | 基础速度 |
| 攀爬 | 需有攀爬速度，否则每尺消耗2尺 |
| 游泳 | 需有游泳速度，否则每尺消耗2尺 |
| 匍匐 | 每尺消耗2尺 |
| 跳跃 | 助跑跳远：力量值（尺）/ 跳高：3+力量调整值（尺） |
| 飞行 | 需有飞行速度 |
| 站立 | 消耗一半移动速度 |

### 困难地形（Difficult Terrain）

移动每尺消耗**2尺**。例如：碎石、泥沼、茂密灌木。

### 倒地与起身

- **倒地（Prone）**：消耗一半速度起身
- 倒地时近战攻击有优势，远程攻击有劣势

### 挤压（Squeezing）

穿过比体型小一档的空间：每尺消耗额外1尺，攻击和敏捷豁免有劣势。

## 五、攻击检定详解

### 攻击检定公式

```
命中判定：D20 + 属性调整值 + 熟练加值 ≥ 目标AC = 命中
```

### 近战攻击

```
D20 + 力量调整值 + 熟练加值
```

- **灵巧武器**：可选择使用敏捷调整值代替力量

### 远程攻击

```
D20 + 敏捷调整值 + 熟练加值
```

- **投掷武器**：使用力量（投掷时可选择力量）
- **远程射程惩罚**：
  - 正常射程：无惩罚
  - 长射程（正常射程~长射程）：有**劣势**

### 近战中的远程攻击

当敌人在5尺范围内时，任何远程攻击都有**劣势**。

### 优势与劣势

| 情况 | 效果 |
|------|------|
| **优势（Advantage）** | 投2次D20，取高值 |
| **劣势（Disadvantage）** | 投2次D20，取低值 |

- 优劣势不叠加（多个优势 = 1个优势）
- 同时有优势和劣势 → 相互抵消（正常投1次）

### 常见优势来源

- 从隐藏攻击（不可见→显现）
- 攻击倒地的近战目标
- 协助动作
- 目标处于受束缚/麻痹/昏迷/震慑状态

### 常见劣势来源

- 攻击不可见目标
- 近战中使用远程武器
- 目标倒地时的远程攻击
- 中毒/力竭状态
- 长射程攻击

### 暴击与大失败

| D20结果 | 效果 |
|---------|------|
| **20（大成功）** | 自动命中；所有伤害骰翻倍 |
| **1（大失败）** | 自动未命中，无额外效果（2024版取消大失败惩罚） |

**注意**：2024版中，大失败不再有额外惩罚效果，只是自动未命中。

## 六、伤害计算与类型

### 伤害公式

```
伤害 = 武器伤害骰 + 属性调整值（+ 其他加值）
```

### 暴击伤害

```
暴击伤害 = (武器伤害骰 × 2) + 属性调整值 + 其他加值
```

- 2024版暴击：只翻倍武器伤害骰，属性调整值和额外加值不翻倍
- D&D 2014版暴击则所有骰子翻倍

### 伤害类型

| 类别 | 类型 |
|------|------|
| **物理伤害** | 钝击（Bludgeoning）、穿刺（Piercing）、挥砍（Slashing） |
| **元素伤害** | 火焰（Fire）、冷冻（Cold）、闪电（Lightning）、强酸（Acid）、雷鸣（Thunder） |
| **能量伤害** | 光耀（Radiant）、黯蚀（Necrotic）、力场（Force）、心灵（Psychic） |
| **状态伤害** | 毒素（Poison） |

### 抗性、免疫与易伤

| 特性 | 效果 |
|------|------|
| **抗性（Resistance）** | 伤害减半 |
| **免疫（Immunity）** | 不受该类型伤害 |
| **易伤（Vulnerability）** | 伤害翻倍 |

计算顺序：免疫 → 易伤 → 抗性（先减半或翻倍，再应用抗性）

## 七、武器精通特性（Weapon Mastery | 2024新规）

2024版引入武器精通系统，特定职业（战士、野蛮人、游荡者、圣骑士、游侠）可获得：

| 精通特性 | 效果 |
|----------|------|
| **Cleave（劈砍）** | 命中后，可对5尺内另一目标造成属性调整值伤害 |
| **Graze（擦伤）** | 未命中时仍造成属性调整值伤害 |
| **Nick（连击）** | 副手攻击不消耗附赠动作 |
| **Push（推撞）** | 命中后将目标推开10尺 |
| **Sap（削弱）** | 命中后目标下次攻击有劣势 |
| **Slow（减速）** | 命中后目标速度-10尺 |
| **Topple（击倒）** | 命中后目标需通过体质豁免否则倒地 |
| **Vex（纠缠）** | 命中后，你下次对同一目标攻击有优势 |

### 精通槽位

- 每次长休后重新选择武器附带的精通特性
- 战士：初始2个精通，4级+1
- 野蛮人：2个精通

## 八、护甲与防御

### 护甲等级（AC）计算

| 护甲类型 | 基础AC | 敏捷加值上限 | 潜行劣势 |
|----------|--------|-------------|---------|
| 无护甲 | 10 + DEX | 无限制 | 否 |
| 布甲 | 10 + DEX | 无限制 | 否 |
| 皮甲 | 11 + DEX | 无限制 | 否 |
| 镶嵌皮甲 | 12 + DEX | +2 | 否 |
| 链甲衫 | 13 + DEX | +2 | 否 |
| 鳞甲 | 14 + DEX | +2 | 是 |
| 胸甲 | 14 + DEX | +2 | 否 |
| 半身板甲 | 15 + DEX | +2 | 是 |
| 全身铠甲（板甲） | 18 | 不可加 | 是 |
| **盾牌** | +2 AC | - | - |

### 法师护甲

```
AC = 13 + DEX（无护甲时）
```

### 徒手防御（武僧/野蛮人）

```
武僧 AC = 10 + DEX + WIS
野蛮人 AC = 10 + DEX + CON
```

## 九、掩护与视线

### 掩护等级

| 掩护 | AC/DEX豁免加值 | 说明 |
|------|---------------|------|
| **半身掩护（Half Cover）** | +2 | 障碍物挡住一半身体 |
| **四分之三掩护（3/4 Cover）** | +5 | 障碍物挡住大部分身体 |
| **全身掩护（Total Cover）** | 无法被攻击 | 完全被遮挡 |

### 视线规则

- **重度遮蔽（Heavily Obscured）**：等同于**目盲**状态
- **轻度遮蔽（Lightly Obscured）**：感知（察觉）检定有劣势
- **隐形**：攻击有优势，被攻击有劣势

## 十、状态与异常

### 完整状态列表

| 状态 | 效果 |
|------|------|
| **目盲（Blinded）** | 无法看见；属性检定中依赖视觉的自动失败；攻击有劣势；被攻击有优势 |
| **魅惑（Charmed）** | 不能攻击魅惑者；魅惑者对目标的社交检定有优势 |
| **耳聋（Deafened）** | 无法听见；依赖听觉的检定自动失败 |
| **力竭（Exhaustion）** | 6级，每级效果见下表 |
| **恐慌（Frightened）** | 恐慌来源在场时攻击和检定有劣势；无法主动靠近 |
| **被擒（Grappled）** | 速度为0；持续到擒拿者无力 |
| **失能（Incapacitated）** | 无法使用动作和反应；不影响移动 |
| **隐形（Invisible）** | 攻击有优势，被攻击有劣势；需搜索检定才能定位 |
| **麻痹（Paralyzed）** | 失能+无法移动说话；力量和敏捷豁免自动失败；被攻击有优势；5尺内攻击自动暴击 |
| **石化（Petrified）** | 麻痹+伤害抗性+不老+重量×10 |
| **中毒（Poisoned）** | 攻击和检定有劣势 |
| **倒地（Prone）** | 匍匐移动；近战攻击有优势；远程攻击有劣势 |
| **受束缚（Restrained）** | 速度为0；攻击有劣势；被攻击有优势；敏捷豁免有劣势 |
| **震慑（Stunned）** | 失能+无法移动+无法听清说话；力量和敏捷豁免自动失败；被攻击有优势 |
| **昏迷（Unconscious）** | 失能+倒地+无法移动说话+无感知；力量和敏捷豁免自动失败；被攻击有优势；5尺内自动暴击 |

### 力竭等级表（2024新规）

| 等级 | 效果 |
|------|------|
| 1级 | 所有D20检定-2；卸除负重速度-5尺 |
| 2级 | 所有D20检定-4；卸除负重速度-10尺 |
| 3级 | 所有D20检定-6；卸除负重速度-15尺；**HP上限减半** |
| 4级 | 所有D20检定-8；卸除负重速度-20尺；**HP上限减半**；攻击有劣势 |
| 5级 | 所有D20检定-10；速度-25尺；HP上限减半；攻击有劣势 |
| 6级 | **死亡** |

- 每次长休移除1级力竭（2014版也是每次长休1级）
- 恢复类法术（次级复原术）可移除1级

## 十一、HP、死亡与恢复

### 生命值系统

```
HP = 职业生命骰 + 体质调整值（每级）
```

### HP归零

当HP降至0时：
1. 如果溢出伤害 = HP最大值 → **立即死亡**
2. 如果溢出伤害 ≥ 最大HP → **立即死亡**
3. 否则进入 **昏迷状态（Unconscious）** 并开始**死亡豁免**

### 死亡豁免（Death Saving Throws）

- 每回合开始投1D20（无调整值）
- **10+**：一次成功
- **2-9**：一次失败
- **1**：两次失败
- **20**：恢复1HP，清醒

| 结果 | 效果 |
|------|------|
| 累计3次成功 | 稳定（HP=0但不再投死亡豁免） |
| 累计3次失败 | 死亡 |

- 受到伤害 → 自动记1次失败；暴击→记2次失败
- 稳定后经过1d4小时恢复1HP
- 稳定后再次受伤 → 重新投死亡豁免

### 稳定（Stabilize）

- 使用**医疗包（DC 10感知/医药检定）**
- 施法**备用医疗**
- **急救动作**：DC 10感知（医药）检定

### 恢复方式

| 方式 | 恢复量 | 说明 |
|------|--------|------|
| **治疗法术/药水** | 按说明 | 即时 |
| **战士回气** | 1d10+战士等级 | 附赠动作 |
| **短休（1小时）** | 消耗生命骰 | 每颗骰=角色生命骰+CON调整值 |
| **长休（8小时）** | 恢复全部HP；恢复一半生命骰 | 每24小时一次 |

## 十二、特殊战斗动作

### 擒抱（Grapple）

**条件**：目标体型不超过你1级以上，且在触及范围内。
**消耗**：徒手攻击（取代一次攻击动作中的一次攻击）

```
被擒抱者 → 力量或敏捷豁免（选择其一）vs 擒抱DC
擒抱DC = 8 + 力量调整值 + 熟练加值
```

**擒抱效果**：
- 被擒抱者速度=0
- 擒抱者移动时拖着被擒抱者（速度减半）
- 被擒抱者可用动作做运动/特技检定尝试挣脱（vs擒抱DC）
- 擒抱者失能/目标离开触及/擒抱者擒抱另一目标 → 解除

### 推撞（Shove）

**条件**：目标体型不超过你1级，触及范围内。
**消耗**：徒手攻击（取代一次攻击）

```
被推撞者 → 力量或敏捷豁免 vs 推撞DC（同擒抱DC）
失败 → 倒地 或 被推开5尺（你选择其一）
```

### 缴械（Disarm | 可选规则）

```
攻击骰 vs 目标的力量（运动）或敏捷（特技）检定
失败 → 目标武器掉落脚下
```

### 冲撞（Overrun / Tumble | 可选规则）

```
冲撞：力量（运动）vs 力量（运动）
翻滚：敏捷（特技）vs 敏捷（特技）
成功 → 穿过敌对生物空间
```

### 爬到大体型生物上（Climb onto Bigger Creature | 可选规则）

```
敏捷（特技）vs 目标敏捷（特技）
成功 → 附着在目标身上，攻击有优势
```

## 十三、双持武器战斗（Two-Weapon Fighting）

### 2024版新规则

```
主手攻击（动作）+ 副手攻击（附赠动作）
```

**前提**：双手各持一把**轻型**武器。

**副手攻击**：
- 伤害骰正常计算
- **不**添加属性调整值到伤害（除非双武器战斗风格）
- 武器精通Nick特性 → 副手攻击不消耗附赠动作

### 双武器战斗风格（战士/游侠）

获得此风格的职业可在副手伤害中添加属性调整值。

### 多重攻击时

```
额外攻击 × N → 副手攻击仍只有1次（附赠动作）
```

## 十四、借机攻击（Opportunity Attack）

### 触发条件

敌人**主动**离开你的触及范围时触发。

### 规则

- 使用你的**反应**进行一次近战攻击
- 只有一次攻击，无论你有多少额外攻击
- 撤离（Disengage）动作可避免触发
- 传送、被推/拉不触发借机攻击
- 不可见状态不触发借机攻击（看不见目标）

### 触及范围

- 多数近战武器：5尺
- 长触及武器（长矛、戟等）：10尺

---

## 十五、突袭（Surprise）

### 突袭判定（2024新规）

如果一方试图伏击另一方：
1. 伏击方投**潜行检定（DEX）** vs 目标**感知（察觉）**
2. 感知检定失败的生物进入**突袭状态**

### 突袭效果

- **突袭的生物**：该生物第一轮无法使用**动作**和**附赠动作**
- 突袭生物第一轮仍可使用**反应**（在其第一回合结束后）
- 不再有"突袭轮"概念，突袭状态逐一判定每个生物

---

## 十六、乘骑战斗（Mounted Combat）

### 上马/下马

- **消耗**：一半移动速度

### 控制坐骑

| 控制方式 | 坐骑可以做什么 |
|----------|-------------|
| **控制坐骑** | 仅可与骑手同步移动（疾走、撤离、闪避） |
| **自由坐骑** | 可独立行动，如攻击（有自己的回合） |

### 骑马战斗优势

- 对体型小于坐骑的**未骑乘**生物近战攻击有**优势**
- 坐骑可被独立攻击
- 坐骑的借机攻击：骑手可让坐骑不触发借机，或将目标引向自己

---

## 十七、水下战斗

### 水下惩罚

| 行动 | 惩罚 |
|------|------|
| 近战攻击（无游泳速度） | 劣势 |
| 远程攻击 | 自动未命中（超出常规射程） |
| 远程攻击（常规射程内） | 劣势（除非弩、网或投掷） |
| 火焰伤害 | 抗性 |

### 溺水

- 可憋气 **1 + 体质调整值** 分钟（最少30秒）
- 0分钟后 → 窒息 → HP降为0，濒死

---

## 十八、临时生命值（Temporary HP）

### 规则

- 临时HP**不是**回复；是额外的HP缓冲
- 优先扣除临时HP
- 多次获得临时HP → 保留较高的值（不叠加）
- 长休后临时HP消失
- 持续时间见来源说明

### 常见来源

| 来源 | 临时HP |
|------|--------|
| 虚假生命法术 | 1d4+4 |
| 激励（Bardic Inspiration变体） | 投骰值 |
| 英雄气概法术 | 施法属性调整值/回合 |

---

## 十九、专注与施法

### 专注（Concentration）

| 事件 | DC |
|------|-----|
| 受到伤害 | DC 10 或 伤害值一半（取高值） |
| 剧烈颠簸/地震 | DC 10 |
| 被巨浪击中 | DC 15 |

失败 → 专注法术终止。

### 战斗中施法

- **1个法术位法术 + 1个戏法**：如果使用附赠动作施法，主动作只能施放戏法
- **法术成分**：语言（V）、姿势（S）、材料（M）
  - 姿势成分需要至少一只手自由
  - 材料成分可用法器/材料包代替（无消耗材料）
  - 在水中无法使用语言成分
