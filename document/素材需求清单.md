# 素材需求清单与生成提示词

本文档用于《碎冠之影》正式版视觉小说式 AI 跑团界面。目标不是做普通聊天 App，而是做一个“可长期扩展的黑暗奇幻视觉小说跑团框架”：画面中央是场景画布，底部是字幕对话框，玩家在 KP 叙事结束后选择提示行动或自由输入行动。

当前前端已经预留场景背景、角色立绘、事件浮层、行动面板、状态面板、特效与音频槽位。素材生成时请严格遵守本文档的风格与命名，避免后续接入时风格散乱。


### 文件与导出规范

- 场景背景：`frontend/public/assets/scenes/`，16:9，至少 1920x1080，WebP 交付，保留 PNG 源图。
- 角色立绘：`frontend/public/assets/characters/`，透明背景 PNG/WebP，长边至少 1800px，半身与全身各一套更好。
- 道具图标：`frontend/public/assets/items/`，透明背景 PNG/WebP，建议 512x512。
- UI 图片：`frontend/public/assets/ui/`，透明 PNG，按钮/面板尽量做九宫格可拉伸版本。
- 特效：`frontend/public/assets/fx/`，透明 WebM、PNG 序列帧或 Lottie。
- 音频：`frontend/public/assets/audio/`，BGM 使用 OGG/MP3，SFX 使用 OGG，保留 WAV 源文件。
- 所有素材不要把中文文字直接画进图片，文本交给前端渲染。

## 新增服务时的清单模板

每新增一个服务，必须同步补一份素材需求清单，标题格式建议为“服务名 + 素材需求”。至少包含：

1. 服务类型与核心体验：如 DND、克苏鲁、赛博朋克调查、校园怪谈、恋爱视觉小说。
2. 统一美术风格：色板、光影、构图、安全区域、负面提示词。
3. 场景列表：场景 ID、用途、文件名、详细 prompt、变体。
4. 角色列表：角色名、身份、性格、服装、表情差分、透明背景要求。
5. 道具列表：剧情道具、消耗品、装备、状态图标。
6. UI 列表：对话框、按钮、面板、图标、主题差异。
7. 特效列表：检定、状态变化、转场、战斗反馈。
8. 音频列表：BGM、环境音、交互音、系统音、角色短音。
9. 接入规则：目录、命名、尺寸、格式、验收标准。

验收标准：素材清单能让美术或生成流程独立开工；前端能根据清单中的场景 ID、角色 ID、道具 ID 无歧义接入；所有素材在暗色 UI、底部字幕框、移动端窄屏下仍然可读。
